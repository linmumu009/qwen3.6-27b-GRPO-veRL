# 教材QA争议裁决与闭卷题面检查（2026-09-07）

结论：已把8条既有争议拆成逐疑点裁决，但不能把新一次同模型判断当作终审。发现明确的流程缺口：审核器会以“有资料可读”为由为题目辩护，与闭卷SFT的用途不一致。修补确定性题面检查后，原151条初筛通过项中15条命中外部材料指代，仍需确认/改写，暂不扩大或训练。

## 方法

- 从冻结二次复核结果精确选取8条原通过、二审质疑项；核验原候选文件、教材文件及来源块哈希。每题仅请求一次5号机百炼`qwen3.8-max`，并发8，不重写答案。
- 输入为原QA、二审问题清单和原子断言、同一教材文本。不给评测题。教材按800字符连续无损分块编号，这些块不是句子，提示要求连续阅读。
- 裁决每项问题为material、wording_only、likely_false_positive、uncertain，提供理由和来源编号。程序核对问题编号完整性、类别及证据编号，并回填原文；编号存在不证明语义支持，未做独立事实核验。
- 同模型看到了旧疑点和断言，可能受其引导；本轮不是盲审，也不是人工验收。代理仅检查了简短裁决理由及2条合成题面，没有审阅完整教材与全部QA。

## 结果和解释

8条中7条格式与证据编号有效，1条编号检查无效；不重试到通过。有效7条包含8个问题：实质类2、措辞类3、疑似误报3。

| 候选 | 自动裁决分类（非事实终审） |
| --- | --- |
| 0068、0108、0044 | 各1项疑似误报 |
| 0072 | 1项措辞、1项实质 |
| 0050、0089 | 各1项措辞 |
| 0102 | 1项实质 |
| 0137 | 证据编号检查无效，保留争议 |

这些编号均带`bookqa-`前缀。不能据此称已证实只有2条错误，也不能把3条疑似误报自动恢复。

裁决理由提供的线索：定义题不必列举所有应用示例；原文明确因果关系可被忠实转述；反之，跨两个列表擅自建立特定支持关系可能超出原文。具体实例的裁决仍需来源核对，尤其“省略范围”和“must”等强措辞不能机械归为错误或无关紧要。

关键审核偏差：0137的裁决将“Based on the excerpt”辩为正常问答框架，但实际部署的闭卷题目不附这段材料，代理确认原题确有此表达。0044的“trade-offs described”是否实质依赖材料仍有歧义；没有机械将所有described都判错，也没有接受同模型的辩护作为放行证据。

## 确定性修补

在既有结构检查中补充`the excerpt`、`this excerpt`、`the passage`、`provided text`、`given text`，保持旧规则。仅作为高风险指代筛查，不是事实评分。对已有151条通过项只读复扫，命中15条：

`0028, 0040, 0063, 0075, 0087, 0106, 0118, 0122, 0132, 0133, 0137, 0157, 0173, 0184, 0192`（均为`bookqa-`编号）。

历史151条初筛结果未被覆盖，不能把未命中的136条称为合格训练集。其余风险仍包括隐含材料依赖、答案范围和同模型审核偏差。

## 下一轮最小改进

先做约40条修订版小样，明确“模型只看到题目、不看到教材”，题面包含全部场景条件；采用源片段编号，程序回填证据；缩短答案并禁止不受原文支持的扩展关系。审核明确区分事实错误、不可独立作答、非必要补充信息，不能因遗漏无关示例就拒绝。修订版属于开发迭代，不是独立验证；需要新小样检查，不在本轮直接生产。

本轮停止在争议归因和检查修补，没有无限复审、生成新QA或启动训练。数据质量检查技能要求把审核分歧与已确认错误分开，因证据不足而保留扩大门禁。
