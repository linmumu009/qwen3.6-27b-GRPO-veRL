保持不变的采样合同

  • prompt 4,096 + response 90,112 = 上下文94,208 tokens；单轨迹超时1,800秒。
  • temperature=1、top_p=.95、top_k=20。
  • 逻辑窗口为物理序列容量的1.25倍，完成一条即滚动补位。
  • 严格2→4→6条早停：累计出现至少一正一错即冻结，仅未决题进入下一波。

证据边界

这是32题×2条的小批交叉工程基准，已消除单一机器偏差，但随机生成长度仍会造成波动，不能宣称TP4对所有负载统计学最优。当前证据足以支持正式效率配置；正式队列的持续吞吐、超时率和候选产出仍应作为后续复核依据。

本报告只含聚合指标与模型哈希，不含prompt、gold、SQL、任务ID、工具输出或服务器路径。原始数据继续保持training_allowed=false。
