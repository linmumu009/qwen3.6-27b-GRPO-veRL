# 40条修订版教材QA（2026-09-07）

完成40条小样，40条均通过本轮自动检查及内容审核。仅交付待抽查候选，不据此认定质量完美，不扩大或训练。

## 来源和方法

输入仍为用户授权用途的原教材CPT数据，文件哈希冻结校验；不用评测题生成，不用旧题改写，也不按历史错题挑章节。固定随机种子20260908（是任意复现种子，不是执行日期），从44章中抽40章，每章抽一个可用来源块，四类题型各10条。具体任务和来源编号在请求前保存。

5号机百炼直连qwen3.8-max，40并发，不加载本地模型。每条一次生成、通过结构检查后一次独立请求审核，不失败重采样。教材来源切成连续800字符窗口编号，窗口不是句子；模型返回编号，程序回填原文。编号准确不等于语义支持，另由审核器逐断言判定。

修订重点：学生只看到题目、看不到教材；题面写全必要条件，禁止外部材料指代；答案提示为1–3句且最多100词，程序只硬校验100词上限；保留范围及may/should等强度，禁止把两个列表臆造成特定因果/支持关系。应用题需题面条件完整且规则来自教材。

审核明确检查闭卷可答性、是否答题、范围、完整断言覆盖、题型和逐断言支持；事实或独立性问题不能降为措辞备注。不要求短答案复述无关示例。material_issues阻止通过，minor_notes不单独阻止通过。本轮minor_notes均为空。

## 判断边界与下一步

高风险仍是同模型生成和审核的共同盲点。40/40只能说明这些候选满足本轮自动规则，不是人工抽查通过，更不是模型训练收益证据。当前`human_review_complete=false`、`ready_for_training=false`。

本轮同时改变生成提示、证据表示、审核提示和样本，不能将40/40与旧版151/200直接解释为提升24.5个百分点的质量收益。样本小、审核标准不同，无可比时间趋势。

下一步应对修订版做一次有限的来源对照抽查（例如四类各2条），重点看答案每个断言、范围和场景条件，而不是继续同模型投票。若通过，再定扩大量及来源分组开发集方案；现阶段不启动SFT。抽查和版本迭代仍是开发过程，不是独立验证。

数据质量检查技能用于拆分结构有效、编号可解析、语义支持与训练验收，并保留同模型自审和新旧不可直接比较的限制。
