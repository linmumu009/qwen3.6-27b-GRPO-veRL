# 去前缀变化31题：来源、任务框架与标签核验

日期：2026-09-23。状态：离线核验完成；新增模型调用0、训练0。正式标签、原P1成绩及上一轮224→229的索引评分全部保留。

## 结论

**当前更优先的问题是测量含义与任务框架，而不是继续训练或寻找更好的统一前缀。** 31个索引得失混合了真实术语区分、同义候选切换、分类层级重叠，以及任务框架被删除的影响。不能把18个修复都解释为学会知识，也不能把13个损失都解释为知识遗忘。

这不等于“所有错误都是题库问题”：来源仍支持部分清楚的术语得失。当前证据不足以把这些变化归结为一个内部机制，也不足以形成可部署的条件处理规则。

## 范围和核验方法

完整纳入上一轮18个修复、13个损失，未按审阅结果删题。两名隔离审阅者分别核验得失组，主审重新检查全部来源引用的精确文字、定位和指纹，并关联冻结题面、269项候选、前后多数答案及自然配对。审阅者可见结果，**不是盲审或独立泛化验证**。

只使用本地归档文本，没有新增网络检索或PDF页面图像复核。未找到来源的结论仅限所查归档，不代表来源不存在。30道变化题有同定义同答案文字的小候选配对；它们只能提供数据内部一致性线索，不能充当独立来源。

全305题中，按既有标签事后定位的优缺点类共12题，原正确10、删除后正确5，修复0、损失5。这是描述性分析：**使用标签得到的分类不能用于推理时路由**，也不能据此拼出“只保留赢家”的处理规则。

## 18道修复对应什么

有10题在本轮归档范围内获得充分来源支持，其余2题缺精确来源、6题存在候选歧义。至少一题只是大小写同名索引切换；另一题虽支持转向正确术语，但存在两个大小写候选，无法证明唯一索引。政治、社会两题的旧概括选项同样与来源章节相符，不能登记为确定的概念修复。

本轮补定位了干散货船与航空托盘的原文，这两题由旧部分依据变为本轮充分依据。这是追加审阅结果，**不追溯改写上一轮冻结的来源A子集及统计**。主审复验32处来源引用的文字与指纹全部通过；精确等级与来源指纹见[安全台账](cpt_neutral_change_audit_20260923.safe.json)。

这是已见得失后的审阅，不能用A子集另算一个“净增”替代全体结论；同一来源的多个定义片段也不是独立知识组。

269项共享候选池中有3组仅大小写、空白规范化后相同的术语；变化题里1个修复和1个损失的前后答案规范化文字完全相同。程序只记录这种现象，没有扩展评分接受集合；缩写和上位/下位关系仍需逐项来源审阅。

## 对上一轮解释的修正

上一轮“定义和候选逐字保留”检查成立；但不能由此推出“被删前缀对所有题都无作用”。至少5道损失题明确属于原前缀所指定的优缺点分类。需要区分**定义文字完整**与**任务分类框架完整**。

历史语义审阅、冻结包、915次输出与评分保留不动，本报告作为追加解释。净增5仍是原标签下的结果，不是来源裁定后的能力净增。来源A也不自动意味着删除前后的任务语义等价。

## 下一步顺序与停止边界

1. 先对完整305题做任务框架和候选关系清点，包含未变化的274题。根据原始题面与来源识别术语匹配、优缺点分类、社会/政治因素分类、残缺上下文；同时登记同名、缩写、上下位关系。审阅输入隐藏前后预测，不能只围绕这31题制定规则。
2. 形成独立于官方索引评分的**诊断规格**：哪些题能唯一裁定，哪些只能裁定概念，哪些须保留任务框架，哪些待来源。原正式评分继续并列保留；不把新规格反向包装成旧实验成功。
3. 只有获得不读取标签/结果的处理规则，才另立生成登记和完整保持对照。当前不采用“识别优缺点后保留、其他都删”的事后策略，不缩候选、不继续搜索前缀。
4. 训练路线仍需来源明确、候选可裁定、任务框架保持后仍存在的稳定错误，以及对缺口有效的干预证据。本轮没有新增训练准入依据；保留P1，不改原阶段B/C结果。

本次交付到31题来源核验为止，上述全305题清点尚未执行。后续目标是提高可解释性，不是靠改评分消除错误。
