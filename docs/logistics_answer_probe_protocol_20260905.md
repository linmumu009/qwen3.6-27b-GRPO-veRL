# 物流 CPT 答案吸收补测与知识化修复

本轮目标是区分三个问题：训练是否提高了金答案概率；模型能否在训练时的文本前缀后生成金答案；题目转换是否表达了正确、完整的知识。完成这些检查前，不把全量 loss 下降解释成答案已学会，也不把不显著解释成无迁移。

## 冻结输入和比较

使用 2026-09-04 原有 Step120、直接题面 CPT 4遍、改写题面 CPT 4遍三个模型，各自在完全相同的直接文本和改写文本上补测。每个模型覆盖 1,672 × 2 条文本；没有重新训练，也不改写历史训练文件。

直接文本的答案起点为 `Correct answer:` / `Correct answers:` 后；判断题起点为 `This statement is` 后。按完整文本 tokenizer 的字符偏移定位答案 token，遇到跨越前缀边界的 token 时纳入答案计分并报告数量。三个模型的输入文件哈希、题目身份和 token 数须完全匹配。

指标包括：

- 答案 token 加权 NLL：只平均金答案部分的负对数概率，降低代表金答案更容易被模型预测。
- 前缀 token 加权 NLL：单独观察题干和模板吸收，避免其变化掩盖答案表现。
- 答案 teacher-forced top-1：每一步都给真实前文时，金答案 token 是否是模型最高概率 token。
- 金答案 token 前缀完整命中：不套聊天模板，从原训练文本前缀开始贪心生成，检查生成开头是否逐 token 等于金答案。该指标不是语义正确率；同义答案也可能不命中。

生成长度按每条金答案长度限制，最多 512 token；超过上限的样本单列。NLL 使用全量金答案，不受生成上限影响。评测上下文是单道文档，不包含原训练块内其他题目的前文，因此能测独立题目调用，但不等同于逐块重放训练上下文。所有原始输出留在 5 号机，仓库只保存汇总。

另加原训练块重放：直接读取两个历史 Parquet 各 64 块，保持原文本、题间 EOS、顺序和块末 EOS；屏蔽每块首 token，与历史 causal-LM 数据适配器一致。以字符偏移标出各题答案，只做前向 teacher-forced 计分，分别汇总全目标 NLL 与答案 NLL。此项与单题诊断共同区分上下文依赖和答案吸收，不涉及新训练。

## 知识化修复

旧程序未完成判断题纠正；它保留命题并追加 true/false。新程序另建候选语料，保留旧文件用于复现。

新转换要求：单选/多选题转换成有明确主体、范围和条件的陈述；否定题保留否定关系；判断题改成由题目和标签支持的正确陈述或最小逻辑否定；不凭 false 标签猜测正确数值。依赖“以上皆是”等选项的答案必须结合完整选项解析。匹配题必须能明确还原对应关系。信息不足、金答案自相矛盾或全文超出上下文时标记待处理。

生成后，再进行单独的自动蕴涵检查，逐项核对极性、范围、全部金答案覆盖、独立可读性和额外事实。生成和检查使用同一本地模型，因此只是自动筛选，不能替代人工复核或独立事实验证。候选文件逐条明确记录这两个未完成状态；自动不通过的题目不回退成旧错误格式。

结构风险扫描为启发式、类别可重叠：全量 1,672 题中，81 题为判断题，179 题触发否定措辞，1,169 题触发匹配措辞或超过 10 个选项的检查。触发风险不等于题目错误；没有触发也不保证没有依赖关系。

## 优化器配置更正

只读核验 5 号机 `/verl/verl/utils/megatron/optimizer.py` 发现当前转换路径没有读取通用 `optim.betas` 字段，而是构造 Megatron 参数后应用 `override_optimizer_config`。因此历史 `betas=[0.9,0.95]` 实际仍落到默认 beta2=0.999。

训练入口已增加显式 `adam_beta1/adam_beta2` 覆盖及运行合同记录。默认取历史实际值 0.9/0.999 以维持复现；若新实验选 0.95，必须通过 `ADAM_BETA2=0.95` 明确指定。这一修复不会改写已完成模型。

## 后续小规模正向验证的条件

先依据答案补测判断是否存在答案写入，再从纠正候选中选取经实质复核的简单题及风险题样本。当前自动审核标记不能冒充人工复核。

小规模实验要同时保存中间检查点并测训练格式答案，比较知识陈述 CPT 与答案专属监督 SFT。两组从同一 Step120 独立启动，保存 optimizer 状态以便真实续训；记录实际学习率、beta 和监督 token 数，而非只报“几遍”。

为避免同时改变文本格式和 loss mask，实施时先做同一问答文本的全 token/仅答案监督对照，再在仅答案监督组单独加入聊天模板。独立知识陈述的 CPT 另作为文本表达方式对照。可以按前一对照的结果依次推进，不必一次启动全部组合；每次只改变一个待验证因素。

如果答案概率没有足够提升，先诊断监督位置、训练强度和导出权重；如果训练格式生成明显改善而原选择题不改善，再测试格式转换和知识调用。只有训练题充分拟合后，才适合把改写题或独立新场景上的失败主要解释为迁移问题。

本轮仍是评测题知识写入诊断。最终交付需要从未参与训练、生成提示和调参的独立试题，以及原 Agent/通用能力回归。
