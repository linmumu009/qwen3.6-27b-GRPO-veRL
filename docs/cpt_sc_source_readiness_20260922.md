## 新补查明确了什么

### 税制：知识可查，题目适用条件仍不完整

沙特税务公告正文明确给出2020年7月1日的税率调整生效时间，进一步说明税率知识有期间条件。检索命中的另一份专业服务指南打开后转到缺页，未将搜索摘要算成原文核验。[ZATCA公告](https://zatca.gov.sa/en/MediaCenter/News/Pages/News-320.aspx)

阿联酋税务局VATP007的第1—2、6—7页区分运输工具本身的供应与运输服务，分别涉及不同适用条件。因此，补充一般税率不能代替交易性质核验。本次用途是核对来源范围，不构成现行税法的完整审计，也不把旧文件直接用作所有时期的训练标签。[FTA原始说明](https://tax.gov.ae/DataFolder/Files/Pdf/AR/07-%20Public%20Transportation.pdf)

对于“所有辖区都相同”这类全称命题，在适用范围确定后，一个有效反例就可能足够，不必机械补齐全部辖区。但不能跳过反例的期间、交易类型与原命题范围对齐；两个相关项目也不能拆成两个独立能力名额。此次保留原B状态。

### 标签代码：相邻标准不能替代目标模板

GS1应用标识符及物流标签资料提供标准化编码线索，但打开正文失败，且检索线索中的数字标识符并未建立与目标单字母处理代码的对应关系。仍需目标工具、模板版本及字典，或范围匹配的跨模板例证。本次不据搜索摘要升级。[GS1标签指南入口](https://www.gs1.org/standards/gs1-logistic-label-guideline/1-3)

### 其他项目：缺的是映射或裁定依据

| 依赖 | 需要拿到的证据 | 不能作为替代的材料 |
|---|---|---|
| 国家扩展商品码 | 国家、申报程序、版本及对应编码规则 | 未指定国家的通用编码长度 |
| 订单与包裹计数 | 实体映射、拆合单、取消事件统计口径 | 单纯减法 |
| DDP采用动因 | 地区、时期、业务门槛及采用原因原始论述 | 仅有条款定义或税收政策 |
| 清关兜底 | 系统策略、触发条件、风险处置 | 国际编码标准 |
| 清关架构权衡 | 系统目标、约束、排除竞争解释的依据 | 通用分布式架构常识 |
| 入库异常归因 | 指标字典、时间口径、渠道维度、排查规则 | 相关指标存在或管理经验 |

全部29组依赖都附有验收条件和恢复触发器。业务流程的有效版本、角色边界与例外处理必须来自相应资料，不能从正式答案解释倒写。
