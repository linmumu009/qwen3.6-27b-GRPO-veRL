## 本轮改变了什么判断

1. **追加数据确实产生了学习，但收益没有累计成全局改善。** 新训练/开发合计从 21/48 到 31/48，同时旧迁移、保持和正式总分回退。来源审核通过与整体训练价值是不同的检查。
2. **旧数据不删除，也会出现旧能力下降。** 增加 16 步、11,698 个序列 token，同时改变混合比例和采样顺序；本轮不能把回退单独归因于覆盖、顺序、干扰或训练量。
3. **不是 JSON 格式失败。** 新任务剩余 17 次错误为漏选 4、多选 5、选项替换 8，全部输出可解析。增加规则应用多样性和检验顺序稳定性，比只修答案格式更有依据；仍不能认定某一个机制已被证实。
4. **P1 继续作为当前参考候选。** P4 的若干能力改善可以指导后续数据审核，不能用这些局部收益掩盖正式结果。本轮没有自动替换模型或启动下一训练臂。
