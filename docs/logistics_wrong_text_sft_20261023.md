# SC-bench / LogistikaBench 错题正文 SFT

日期：2026-10-23（北京时间）。本轮使用评测题训练，所有成绩均为同题训练成绩，不是独立测试或泛化证据。

## 用户要求与固定协议

- 从开源续训 Step120 的完整 HF 权重开始，全参数 SFT，初始化新优化器。
- 五号机全部16逻辑NPU，训练1个 epoch，每50个优化步以及最后一步进行两套数据集的全量生成式评测。
- 训练集取历史 Step120 错题与本地原生模型错题的并集；不使用此前全量同题 SFT 模型作为初始化。
- 按全1,672题总答对数选择最优，同分保留较早模型；Step120 的本轮重测也参与比较。保存每次成绩，最终仅保留一个最优模型入口，不改动历史模型。

## 输入与答案设计

沿用9月3日同机同栈评测原始输出，逐题重新解析预测，核对题目、全部选项、金答案、题目指纹、覆盖率与保存正确性。原生错误309题，Step120错误303题，后者包含在前者中。并集309题，其中 LogistikaBench 271题、SC-bench知识题38题。

使用全部原选项，按固定随机种子对每题重新排序，并同步重映射正确索引。监督目标先输出正确索引 JSON，再完整输出全部正确选项的正文；多选题保留全部正确项，不生成未经验证的解释。全部答案正文及EOS计算损失，题干和选项不计算损失。没有只监督固定字母或索引的样本。

训练系统提示明确要求“索引＋正文”；评测沿用正式的仅索引 JSON 提示和精确集合评分。两者输出指令不同，评测仍检查模型是否能按正式要求作答。训练时打乱选项只是一种防位置记忆措施，不能据此声称模型学会了可迁移知识。

真实分词预检：309条、327,616个序列token、9,705个受监督token，最大3,052 token。batch=3，恰好103步，每题只曝光一次，没有丢弃尾批或补样本。评测步数为0（基线）、50、100、103。

## 执行和资源

训练为TP4×PP2×CP2，16进程、BF16、batch3、microbatch1、4,096上下文、固定学习率2e-6、Adam 0.9/0.999、weight decay 0、梯度裁剪1.0、关闭MTP训练。旧Step120分布式检查点已不存在，因此直接严格加载保存的Step120 HF权重，不从原生模型代替初始化。

每次保存后，16个训练进程将模型和优化器状态卸载到CPU内存；rank0导出并启动两个各8卡的vLLM副本，各测半套题，合并后严格检查全部1,672题无重复、无遗漏。评测后恢复同一优化器、随机状态和数据迭代器继续训练，不重启训练、不重置Adam，也不重复前50步。

评测关闭thinking，temperature0、seed1024、输出上限128 token、4,096上下文，每个检查点一轮；为效率未做三轮多数票，不能与历史多数票分数当作完全相同的估计。结果包含各数据集答对数、总分和解析失败数。候选只在严格高于已保存最优总分时替换最优模型，较差候选的导出权重会删除；完整评测成功后清理本轮临时分布式检查点。
