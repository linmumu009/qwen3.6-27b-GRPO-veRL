# 教材 QA 二次复核：暂不扩大（2026-09-07）

原通过的20条抽样中，12条再次通过、8条出现审核疑点。这个结果说明初筛与逐条断言复核存在明显分歧，尚不足以支持扩大；不是已经证实40%的答案事实错误。

## 方法和粒度

一条记录对应一个原候选QA，原200条、151条通过的历史产物完全保留。固定种子20260907，在通过项的定义/比较/条件/应用四层各抽5条，另在结构拒绝和内容拒绝各抽4条。样本编号、候选文件哈希和来源哈希在API请求前冻结；逐条校验来源块哈希。

28条全部使用5号机百炼`qwen3.8-max`，并发28（不超过64）。审核请求不展示原先的通过/拒绝结论，也不接收评测集；接收原QA和同一教材来源，要求列出所有事实断言、逐条引用及范围、独立性等检查。API输出的支持引用再做本地逐字验证。不加载本地模型，不生成新QA，不修改原答案。

这是同模型、不同提示的自动复核，不是独立审核，更不是人工验收。“盲于初审结论”并不能消除同模型偏差或严格提示导致的误报。

28条无请求/解析失败或截断。20条通过样本属于题型等额抽样，而不是全体151条简单随机抽样，不外推总体错误率。12条再通过也不直接升级为训练验收。

8条原通过疑点中，2条出现至少一个被审核器判为不支持的断言；2条独立性标志未通过；范围标志、完整覆盖标志各1条未通过；8条均有非空问题列表。类别可重叠，不应把“非空问题列表”都解释成事实错误。需进一步核对具体问题的严重性和审核器是否误报。

暂挂疑点编号：`bookqa-0068`、`bookqa-0072`、`bookqa-0108`、`bookqa-0050`、`bookqa-0089`、`bookqa-0137`、`bookqa-0102`、`bookqa-0044`。这是单独复核记录，不覆盖原始初筛结果。其余131条原通过项尚未二次复核。

对全部32条结构拒绝做确定性引用分类：4条仅空白差异，27条在空白归一化后仍不匹配，1条引用缺失/过短。内容不匹配可能涉及改写、标点或拼接，并不自动证明引用内容虚假；但现有逐字来源链无法核验，不能直接放行。

本轮API用量109,319输入tokens、9,680输出tokens，共118,999 tokens。没有扩大量生产或训练，无同口径历史趋势可分析。

## 风险与最小改进

- 高风险：初筛与二次复核不一致。先对这8条疑点进行证据对照裁决，区分真实支持性问题、次要表述问题和审核误报；不反复请求到通过为止。
- 中风险：引用由模型重新抄写不稳定。下一版可给源句编号，要求返回证据编号，由程序回填原文；应用题仍须校验推导条件，证据编号存在不代表结论成立。
- 仅允许可追踪的空白归一化作为引用诊断，不在本轮自动救回拒绝项。内容支持性门禁不能因排版修复而跳过。
- 再做小样时要求短答案、必要范围条件明确、删去未被要求的扩展建议。先验证同一小样流程，再决定扩大。
- 当前整体保持不可训练状态。既有评测词面筛查未重做（QA未改），原先“无命中”仍不等于语义零泄露。
