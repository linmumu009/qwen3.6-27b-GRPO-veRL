# P2：固定更新次数的保持混合对照

2026-09-16。状态：具体设计已登记，数据预算待实测，未开始训练。

P1主结果保持51→49/80，唯一追加运行52→50/80，均净降2题。新增表达和条件两层在追加运行仍分别6→11和7→11。基线跨运行有2题正确性变化，P1有1题变化；净差方向复现不等于独立训练重复或总体稳定遗忘。停止相同推理复测，不挑高分覆盖原始结果，不启动正式评测或C/D。

## 唯一实验变量与固定项

检验在相同优化器更新预算下，增加历史保持训练的采样占比能否减小保持损失，同时保留迁移信号。

P1是180条新任务曝光加135条历史保持，P2计划120条新任务曝光加195条历史保持，总计仍315条、batch3、105步、1遍。重新从原Step120 HF初始化和创建优化器，学习率5e-7、训练seed1、拓扑及其他配置全部沿用P1。新任务仍为原60道，历史保持仍为原135道；不新增题、标签或监督文字，不读取80道保持评测内容来选择训练样本。

固定315条曝光预算时，提高保持份额必然减少目标份额。本试验估计的是这一采样配比的整体效果，不能将“更多保持”与“更少目标曝光”拆成两个独立因果贡献。

## 可复现的配比构造

直接读取P1已冻结的训练消息顺序并校验指纹，不重新制题。每个规则族原有6道题、每题3个曝光。每族按题ID的SHA256排序，前2题移除答案监督曝光0，后4题各移除一个解释曝光，按排序交替选曝光1或2。每题最终保留2个曝光，所有60题仍出现；10族共移除60条，其中20答案、40解释。新任务的答案/解释总比例仍为1:2（40/80），每族仍等权。选择完全由来源任务ID决定，不能按评测表现选题。

从原135条历史保持训练ID中按SHA256排序取前60条，每条追加一次，原135条保留。把追加保持消息原样放入上述60个被移除的位置，只改重复记录ID以保持唯一；其余255位置和内容不变。这样固定总记录数、预排列位置和后续采样器种子，避免另外引入一轮随机重排。历史保持仅是训练回放，不与保持评测合并。

## 开训前审查门槛

1. 逐条验证315条、120/195配比、60个目标题各2曝光、135个历史保持题全覆盖、新目标答案/解释40/80，以及255个未替换位置完全一致。
2. 以冻结分词器实测序列和监督token；检查监督起点、EOS、最大长度、训练器加载及实际采样顺序。报告相对P1的87340序列/12202监督token差异。只匹配记录和105更新步，不声称精确token或计算量匹配，不用无关填充凑token数。
3. 审查只变采样配比：题目、选项、标签、每条消息、模型起点、学习率、种子、batch和训练引擎配置不改；确认保持评测及封存没有进入训练。
4. 核对空间与资源锁、形成独立llin模型目录，保留P1及旧产物。预算/数据不符则暂停修复，不临时修改学习率或步数。

## 结果与停止规则

只执行一轮P2训练，不搜索多档配比。训练后用同180题同顺序同协议一次测量，10封存题仍不查询，正式双集暂不运行。两个Step120基线都保留，P2分别相对主基线及追加基线报告，不选较低基线获取通过。

探索信号沿用P1：新表达及新条件每层至少净增2题、至少2规则族净改善；保持总数不得低于任一已观察Step120基线，即至少52/80。该保守52门槛是P2查询前设定的确认要求，不回改P1原登记。逐族及逐题修复/损失同时报告，不仅看总分。

若保持改善但迁移信号消失，则记录固定预算下的权衡并停止扩量；若保持继续下降，也停止该单变量路线，先作原因判断，不自动扫更多混合比例。即使全部通过，也只进入扩大数据及确认评审，不自动晋级或宣布+3个百分点目标达成。
