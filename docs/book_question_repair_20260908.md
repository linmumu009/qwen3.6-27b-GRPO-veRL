## 为什么又排除6道

1. 操作规程仍被当作通用知识，闭卷评分要求说明未展示文本“没有提到什么”。
2. 从未描述某设备的特征，推导该设备没有该特征。
3. 仍要求不加框架限定地回答“恰好两个本质特征”。
4. 教材举例时长被改成典型周期，且评分加入题目未问的历史数据点。
5. 原因解释题要求背教材百分比，并混用销售额与销售成本分母。
6. 常见结构形式被改成设备必须满足的结构依赖。

这些不是JSON格式问题，而是问答与评分内容问题。多轮同族模型可能共同接受同一个错误；收紧提示词有帮助但不能保证消除。第一轮审核也曾把正常的技术事实记忆误当作闭卷题缺陷，因此不能机械接受审核理由。
