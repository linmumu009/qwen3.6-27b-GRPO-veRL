# 八题复核与同文本监督范围诊断

用户明确允许将最多8道题的题干、金答案和新陈述显示到当前 Codex 任务。本轮严格查看8道，没有追加其他题目。

## 复核结果

当前助手核对的是候选陈述是否忠实于题干和金答案，未执行外部事实核验；7道可原样保留，1道需去除章节引用。后一修复仅删除章节定位，不更改专业内容。原候选全量文件保持不变，复核后的8条陈述另存于5号机。

样本包含1道 true 判断题、若干定义/匹配题和普通题，没有 false 判断题。此次抽查不代表1,582条自动通过候选全部可靠，也没有完成错误命题纠正的实质抽查覆盖。

## 对照设计

训练使用这8道对应的问答文本，移除正确答案开头的列表标记，每题为一个独立样本，不打包其他题目，也不套聊天模板。复核后的知识陈述另外保存，本轮不使用，以免同时改变文本与监督范围。

两组均从相同 Step120 模型态独立初始化新优化器，使用相同数据顺序、模型拓扑和64步预算。唯一处理变量是 loss mask：全文组监督所有真实目标；答案组仅监督答案和 EOS。损失按相应监督目标归一化，因此答案相对权重也随 mask 改变，这是本轮所研究的机制。

实词元门禁确认两组 input_ids 和 position_ids 完全相同，EOS 均受监督，首 token 回卷均被屏蔽。每遍输入491个含 EOS token，全文监督483个、仅答案监督47个；答案前向诊断另排除 EOS，计39个答案 token。

计数关系：8题 ÷ 每步4题 = 每遍2步；32遍 × 2步 = 64步；491个输入token × 32遍 = 每组15,712个累计输入token。重复曝光不增加独立知识量，仍然只有8题。全文组累计监督15,456个目标token，答案组累计监督1,504个目标token（其中256个为EOS）；两组输入量一致，但监督目标数量不同。

| 项目 | 两组共用设置 |
|---|---|
| 样本数 / 全局 batch | 8 / 4 |
| 步数 / 曝光次数 | 64 / 32 |
| 学习率 | 2e-6，最低也为2e-6，前两步有效预热 |
| Adam beta | 显式0.9 / 0.999 |
| 拓扑 | TP4 × PP2 × CP2，16 NPU |
| 验证 | 每16步在同8题上记录训练集验证损失 |
| 保存 | 最终模型、优化器和extra状态，严格HF导出 |
| 晋级 | 禁止；这是训练题拟合诊断 |

考虑5号机约1.1TB剩余空间与全参优化器状态体积，本轮只保留最终检查点，中间保存逐步日志与16步间隔的验证指标。两组开始前均要求至少450GB空闲磁盘。不同监督范围的训练 loss 分母不同，不能直接横比其绝对值；最终用同一答案NLL和严格前缀续写指标比较。

## 基线与解释边界

Step120 在这8道独立前缀上答案NLL为1.8344，答案token top-1为58.97%，完整金答案前缀逐字命中0/8。0/8不代表语义知识为零：这是不带选项、不套聊天模板的严格token续写测试，同义输出也计错。

此实验首先检验训练管线在极小可信样本上能否加强金答案概率并提高原样生成。即使达到8/8，也只证明这些训练题能被拟合；后续仍需另测表达改写、新场景、聊天格式和通用/Agent回归。

历史1,672题实验与本轮同时存在样本规模、曝光次数、学习率、打包方式等差异，不能把两轮差距单独归因于某一个因素。本轮内部的全文组和答案组才是同文本、同预算的监督范围对照；且各只有一次运行，不估计跨训练随机种子的方差。
