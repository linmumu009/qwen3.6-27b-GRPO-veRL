## 有限正文复核：不要被裁判共同偏差带偏

当前任务选择5道教材自建样本检查教材、CPT回答和两轮评分（非随机总体审计，正文不提交）：

- **PBL定义**：闭卷已正确解释按可用性/战备等结果付费而非按零件数量，裁判却要求题目未明确询问的具体益处列表。这是明显的评分有效性疑点，不应据此标记缺少PBL知识。
- **Journey management**：闭卷偏向人身/治安风险环境，遗漏道路设施和地形因素；但裁判把合理环境例子简单称为教材未支持，又有参考答案内容超出所选完整片段的风险。可能有范围覆盖不足，不是整个概念不会。
- **矩阵图与流程图**：题目未明确矩阵图类型，教材说的是特定示例中的时间表示，模型按跨职能关系矩阵理解。存在术语歧义，不能把另一合理理解直接判为无知识。
- **库存持有成本**：组成项正确，但CPT闭卷和资料回答都把160,000+30,000+50,000加成211,000，而正确结果是240,000。两轮裁判也识别了此算术错误。这是一个可核查的真实错误，不支持“给资料即可解决所有问题”。
- **计酬方式分类**：题目问名称与组成，却在评分中要求额外求总工资；两轮均判rubric无效，已排除。题型标签也名为计算而实际主要是分类，不能把名义计算题数量当作实际计算覆盖。

没有手工替换原始分数，也没有重评到一致。35题只是机器评分一致，并非35题全部经过内容认证。复核表明仅加强提示词不足以消除同族裁判的共同偏差。

## 面向下一批的决策

1. **不按定义题的低分比例大量扩充定义复述。**这一低分已发现被附加清单评分污染，不能解释为最大知识缺口。
2. **停止等比例复制当前简单计算。**样本7道一致项中6道两模型本来就会；保留少量基础计算，新增计算应要求选择依据、单位/容量边界、结果校验，不只替换数字做加减。一个算错实例不足以估计系统算术缺陷率。
3. **优先组织条件明确的应用与辨析。**题面明确要作出的判断、必要假设、概念具体含义；答案先给结论和必要依据，不把教材附加描述全部变成评分要求。此为有待试训验证的设计，不是统计证明的最优配比。
4. **整批处理，不再围绕5个例子反复修补。**把当前365道训练候选按上述口径批量检查最小必要答案、题型与条件，隔离明显有问题项；开发71道不用于训练，也不按开发错题生成新题。
5. **调整原来“先扩到2000–3000再训练”的顺序。**目前数据已具备数百道规模，而瓶颈是学习价值与评分有效性；先用经批量整理的首批做小规模SFT对照，再决定是否值得扩量，更能验证目标。不能承诺365道足以最终达到交付指标，只能用于低成本方向验证。训练前冻结预算、数据与域内/Agent/通用回归口径；本轮未执行该训练。

因此本轮交付是完成预答与扩量决策分析，不是再次得到几个“可用题”就收尾，也不是声称已实现供应链能力提升。旧436道候选保持不变；仍需下一阶段批量整理和受控SFT，不能直接把本轮裁判标签当成训练权重。
