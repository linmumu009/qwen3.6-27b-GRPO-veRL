## 已修复的实质问题

- **铁路速度分类：** 分开记录建设类型、主段设计能力、观测运行速度和短连接段速度；排除未建模的改造线路地形例外。“N”明确仅指不属于所问两类。
- **铁路长度：** 分开记录原始建设用途、当前用途、公共通行状态、轨道数和路线长度；明确EU统计框架。限定公共所有且接入网络，避免私有线及独立网络条款的范围歧义。
- **答案：** 每个选项保留原始前提、逐记录判定和总计；逆推题枚举可选补全，最小成本题比较全部可行方案。另一套计算实现验证结果，篡改题面、答案或判据会失败。

来源及题面审核由同一Codex作者完成；计算实现分离不等于独立领域专家审核。20题在上述限定情境内的前提与来源规则一致，不代表已经证明语义独立或训练价值。
