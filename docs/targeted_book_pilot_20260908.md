# 定向教材 SFT 短程试验 v1

## 训练前冻结的方案

用户在候选整理完成后授权“开始”。从纯教材 CPT4x 第116步的分布式权重重新加载，清空优化器历史；不是从旧教材2000问SFT或评测题派生模型继续训练。此轮是低暴露量的可行性/风险试验，不是最优超参数或数据筛选因果收益证明。

- 候选池67问、维护16问、开发39问、隔离55问的SHA按上一轮冻结。
- 为整除全局批次8，按固定ID哈希从一般物流/仓储/运输各保留1道候选不训练；其余64候选加全部16维护，共80问。6道物料搬运候选全部保留。保留3问不是新增开发集，也不用于选择模型。
- 仅原问法，闭卷，使用预答时同一system提示；只监督参考答案和EOS，不训练变体、证据块、评分点、评测题面或标签。
- 一遍、10个优化器步，全局批次8；学习率固定5e-7，无warmup，weight decay 0，梯度裁剪1；16设备TP4/PP2/CP2。保存第5/10步，不自动加轮次。
- 总序列15,491 tokens；答案与EOS监督7,183 tokens；最长序列275 tokens；80问整除批次，无训练尾部丢弃。第5步只是半程快照，不假称精确监督总量恰好减半。
- 现有训练器训练和验证均drop_last。禁用它的开发NLL循环，改为完整39问生成式开发评估，避免将漏掉7问的验证损失当作全量结果。

## 固定评测口径

两个检查点均对39道开发题及16道训练内维护题运行原问法/等义变体×闭卷/原教材证据四条件，每个检查点220次回答。完整回答、finish reason及源/候选SHA均保存；维护题结果单列，不能视为独立回归集。基线使用冻结的纯CPT对应题ID四条件结果，后续评分须将基线及两个检查点匿名混排，维持同一评分点与裁判设置；评分失败或输出截断分别统计，不当作知识错误。

首要描述性指标：39道开发题的闭卷双问法通过数及逐题得失，开卷仅用于诊断；需明确39题来自少量相关概念组，不使用题级独立假设夸大显著性。无论结果好坏完整报告5/10步，不根据开发表现追加训练后再隐藏早期结果。

SC-bench/LogistikaBench仅对预先固定的最终第10步运行冻结1672题、原提示和三次重复，多数结果与纯CPT1371/1672及逐题迁移对比。官方题不进入训练或教材裁判API；不依据这两个集选择5/10步。历史反复观察仍限制其作为独立最终测试的解释。

此启动脚本完成训练、两个教材预答、最终官方推理后停在 `inference_complete_grading_pending`。教材匿名评分和最终比较仍需后续完成，不把推理结束视为实验验证成功。未加入经过核实的独立Agent/通用回归集，因此即使领域分数上升也不认定可替代交付模型；当前模型不部署、不覆盖任何基线。
