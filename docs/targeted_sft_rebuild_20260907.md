# CPT 后的需求驱动 SFT：诊断、构造、筛选和训练

## 目标与当前阶段

用户要求：先诊断纯教材 CPT 的短板与旧数据训练价值，再重建 SFT 数据，最后从纯 CPT 起点重训。此请求包含后续训练授权，但不允许跳过诊断/数据门槛。当前已完成纯 CPT 冻结诊断复测、旧数据审计及新数据筛选协议；未生成新版数据、未启动新版 SFT。本文是可执行数据组织协议与阶段记录，不是整个重训任务的完成声明。

起点固定为纯教材四遍 CPT 第116步。不得沿用已回退的教材 SFT 模型，也不得使用评测题 CPT/SFT 分支或其优化器状态。

2026-09-08阶段更新：[第一批概念组记录](targeted_book_groups_20260908.md)已完成120组尝试、37组111问来源审核通过、444次CPT预答及百炼筛选。四池为63问候选机会、14问维护、10问开发、24问隔离。新版候选已生成并组织，但主题/开发覆盖与语义去重门槛未满足，未重训。上述“未生成新版数据”是9月7日阶段状态，不是当前状态。

## 先修正对旧实验的理解

旧训练一遍、学习率1e-6，不足以证明更新幅度过猛；真正已证实的是没有在训练前测定目标模型需求。旧生成器按44章近似均衡，定义504、比较492、条件496、应用508条，来源审核后按保留顺序取满2000，并非完全没有应用题。

新审计从已有183道有效开发题评分得到：定义满分7/51→18/51、比较8/46→24/46、条件6/37→11/37、应用20/49→25/49。应用题逐题评分提升12道、下降10道；名称为“应用题”不代表难度、规则应用或边界对照足够。上述开发题分数不能证明某条训练数据的边际价值。

纯CPT错误分布必须用其301道原错题，而不是用SFT新增47道错题替代：物料搬运125/696、运输70/404、仓储50/202；三类共245/301（81.4%）错题。仓储错误率24.8%，前两类约18.0%和17.3%。小类SC采购4/12错误率虽高但分母很小，不能直接用比例主导配额。

## 诊断证据如何使用

1. 旧Step120实验为303错题+60正确对照。纯CPT301错题中298道落在旧363题里，3道不在。先复用原题、原教材及原基础探针在CPT上三轮复测，避免换模型又换题。
2. 旧363题中259份审核缺失/无效，不能用作“资料不足”的结论。13份自动证据门禁通过也不是专家认证。复测只更新模型行为，不自动提升这些资料/探针的可信度。
3. 历史8题复核、4题补证和12问定义/辨析/应用测试仅支持混合问题；只针对Step120，不能宣称CPT“知识都有，只缺推理”。本轮不扩大私有评测正文进入当前会话或外发API的范围。
4. 复测分组以CPT历史正确/错误重标，仍不是新抽取的代表性样本。原诊断指令与正式评测不同，只作条件配对。其余3道遗漏保留为诊断覆盖缺口，不凭空归因。

机制标签使用：知识调用机会、条件/概念边界问题、应用机会、题型/表达问题、输入/标签问题、证据不足与未决。闭卷错而开卷对，只说明有资料可改善，不证明参数中没有知识；基础题正确、应用题错误也不自动证明一般推理缺陷。

### 本轮CPT复测已完成

结果见 `cpt_targeted_diagnosis_results_20260907.safe.json`。363题、四条件中可用任务各3轮，共2634次生成，全部自然结束。298道CPT历史错题当前闭卷8/298、带原教材50/298，配对48道改对、6道改错；其63道有效基础探针闭卷57/63、带教材62/63。65道CPT历史正确对照在闭卷与带教材下均60/65，实为3道改善和3道干扰相抵，不是逐题完全相同。

298道历史错题只有6道继承的自动证据门禁通过，不能把其余292道当成缺知识或缺推理。其中有3道应用复核候选，但这些仍使用旧的浅层探针/证据，先前对Step120的复核已揭示这类前提不稳；本轮不把候选数当成确认机制。63道基础题不是298道原题的等难度替代，不将57/63当作“知识掌握率”。

阶段决策：优先构建来源完整、先决知识—概念边界—情景应用成组的独立教材候选，再用CPT预答识别学习机会；不能从当前不充分证据直接给所有301道错题贴因果标签，也不能将原题或派生资料包作为新数据模板。

## 新数据不是把评测错题改写

数据生成器只接收教材与宽泛主题/能力配额，不接收评测题面、选项、金标签、派生基础探针、定向补证包或逐题裁判解释。评测最多提供汇总层面的主题优先级；这仍是受基准观察影响的数据设计，不能宣称正式评测从未被使用。

来源先标概念与规则，之后由5号机百炼qwen3.8-max生成；本地目标模型只回答用于诊断，不充当QA作者。第一批拟生成120个概念组、每组3–4问（约360–480候选），不是先承诺凑满2000。最终主题配额必须等CPT诊断与教材支持范围核对后冻结，不能只由上述错题数机械决定。

同组题以一个有依据的规则为中心，包含必要的定义/先决知识、相近概念或适用边界辨析、独立业务情景应用；只有来源明确支持时才加改变一个条件的对照情景。不得编造数字、法规、企业制度来提高难度。开放式问答为主，部分题可采用独立编写的选项与简短依据，不把训练变成只背选项字母。

监督答案应为直接结论+必要条件+简短、可核验的应用依据；不强求每题长推理链，不让答案堆入无关知识。所有答案中的实质断言都要能对照来源；题目给足闭卷所需的情景信息。

## 每条数据通过两道门

**质量门**：来源真实可追溯；问答独立完整；答案及全部条件有支持；比较对象明确；若含选项则正确集合唯一明确；来源口径无混用；不依赖缺失表图；程序与语义审核去重；与评测、旧诊断探针隔离。来源审核的通过不是训练价值证明。

**学习机会门**：冻结纯CPT模型先答，再评分；不把参考答案或打分点给闭卷模型。预设两个独立呈现条件（固定改述/选项排列，不是把温度0同文重复当独立样本），闭卷与提供支持材料各一次。裁判依据提前冻结的评分点，保留原始输出和终止原因。题面变体必须保留原含义并独立过质量门。

| 观察 | 初始去向 |
|---|---|
| 两个闭卷条件均完整正确 | 维护池，低优先级，不占主要补短板预算 |
| 闭卷均未完整正确、开卷均完整正确 | 知识调用/混合学习机会池 |
| 先决知识通过、边界或应用失败，但证据充分时通过 | 应用机会池；仍非纯推理缺失证明 |
| 两个闭卷条件不一致 | 稳定性复核，不直接当高价值题 |
| 开卷仍未完整正确、裁判证据不可靠或生成异常 | 未决复核/隔离，不直接拿最难题训练 |

`select_targeted_sft_records.py`实现以上保守门禁，只输出选择记录，不自动导出训练数据。目标模型做错只是候选学习机会，不保证训练后有收益；不把loss高、答案长或教师“难度分”直接当价值。

## 切分、混合与验收

- 概念组及近重复簇整体切分，切分先于按目标模型表现筛选；开发组不回流训练。来源重叠与CPT已读过教材须明确记录。保留已有186题为历史对照，不因看过其成绩再挑题把它当全新开发集。
- 训练集中主要使用经过复核的学习机会组，同时保留少量稳定正确的覆盖维护组；具体比例和概念上限在首批有效数据分布出来后冻结，不预设一个未经验证的“最优比例”。同概念多种问法受上限约束，按tokens记录真实暴露量。
- 检查主题覆盖、能力类型、来源支持率、模型预答表现、排除原因、近重复与切分泄露、答案监督tokens、最终格式。不能以“到2000条了”作为启动条件。
- 初始训练计划：纯CPT起点、fresh优化器、答案/EOS监督、保留多个低暴露检查点，使用独立开发集选择；不直接复用旧226步方案作为新数据的默认步数。学习率、token预算和检查点数量待数据验收后冻结并检查设备/磁盘。
- 衡量数据选择是否真的有价值，推荐将“需求筛选子集”与“同一质量合格池的分层随机子集”作相同监督token预算对照。若只训练一个臂，只能判断新配方效果，不能证明筛选机制的贡献；不把随机子集选自不同来源/答案长度当公平对照。
- 正式评测仅用于冻结候选后的结果报告，同时保留原Agent/通用能力回归。回归集可用性与运行配置尚需核实，未通过前不得宣称满足交付目标。

## 研究依据与适用边界

[LESS（ICML 2024）](https://arxiv.org/abs/2402.04333)研究针对目标能力的数据选择，说明“有质量”与“对目标有效”是不同问题；其梯度影响方法需训练/梯度存储等额外成本，本方案未实施LESS，不将简单预答筛选伪称为LESS或影响力估计。[LIMA（NeurIPS 2023）](https://arxiv.org/abs/2305.11206)提供小规模高质量指令数据的研究案例，但不证明本项目只需少量问答，也不证明SFT只改变风格。实际训练增益仍需本模型的受控实验。
