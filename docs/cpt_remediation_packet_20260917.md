# 四项薄弱能力的新数据与训练前测（2026-09-17）

## 本轮目的

按照上一轮确定的路线，为拣选指标、批量成本、串并行作业和分时运力编写新训练题，再用不同推理结构的开发题检查迁移。保留 P1 的累计训练内容，避免再做只改变学习率或重复旧诊断题的试验。

本轮完成来源编写、语义修订、盲复核和两个模型的前测。**尚未执行新训练或正式双集重测。** 题目质量的裁定与模型闭卷得分分开，不以模型答对与否选择训练题。

## 数据范围

| 分区 | 题数 | 用途与边界 |
|---|---:|---|
| 新训练 | 16 | 四项能力各 4 题；正确项数 1、2、3、4 各 4 题 |
| 新开发 | 8 | 四项能力各 2 题；正确项数 1、2、3、4 各 2 题 |
| 来源隔离的保持检查 | 12 | PEST、ABC、订货点、铁路统计、延迟差异化、运输合同；来自 4 个历史开发来源组 |
| 共享训练来源组的保持检查 | 8 | 仓储职能、检查/包装/发运、外包管理、持有成本；单独报告，不能称为未见来源 |

共 15 个来源单元。四项修复能力来自同一个历史训练来源组，训练与开发共享知识规则；这是不同任务构造的开发检查，不是独立知识域或最终泛化认证。没有真实 Agent 工具操作或流程执行测量；那是另一个未测任务，不作为本次知识选择题数据冻结的前提。

开发题包含合并订单、丢失分组标识后的证据充分性、成本区间的保证、跨批次共享启动成本、反推释放时间、作业中断、运输衔接和不确定容量。它们与训练共享基础规则，但增加了明确的新条件或决策结构。文字重叠率仅辅助检查，不能证明语义独立。

## 质量审核与修订

- 205 个冻结来源单元、121 条归档来源记录及 212 条引用关联核对通过；其中 58 条引用没有可逐字比对的摘录，使用完整归档文件指纹和记录关联核验，不声称全部做过逐字摘录核对。
- 44 题与 2,353 个历史规范化问题签名排重，通过相同题和数字替换签名检查；未读取仍封存的 10 题。
- 70 项精确有理数等式通过，并另用集合计数、成本组合枚举、时间步模拟和容量枚举验证关键推理。语义对应仍由操作者审核，程序不能自动认证自然语言。
- 作者答案、真假标记、解释和算术校验均不提供给盲复核模型。审核输出必须同时满足四项真假标记、最终索引和作者键一致，且范围等六项质量标志通过；四项全选合法，矛盾或截断不会自动修正。

保留原版，另存最终修订版，四题均不改答案键：

1. 明确 R、S 是两个物理库位，避免被解释成可多库位存放的 SKU。
2. 明确扫描记录不含未完成指令，并覆盖每条已完成指令。
3. 将“更便宜的干预”明确为含手续费的最终批量总成本，避免只比较干预费。
4. 将“可行方案”改为“待检查方案”，避免提前声称已满足截止时间与劳动预算。

最初排队的两题补测在开始推理前取消，合并为四题一次补测；首次启动因缺少结果父目录在模型加载前退出，创建目录后用未改变的代码重启，失败日志保留。这两次调度事件没有产生重复模型回答。

## 固定前测协议

原版 220 次调用：P1 的 88 次双选项顺序闭卷、44 次来源盲复核，加 Step120 的 88 次闭卷。最终修订四题另做 20 次调用：两个模型各 8 次闭卷，P1 再做 4 次盲复核。**合计 240 次，最终视图包含 176 次闭卷和 44 次复核，其余保留作版本审计。**

固定 seed 20922、温度 0、关闭 thinking、闭卷 96 输出 token、复核 1,536 输出 token、上下文 8,192、TP8。两种选项顺序按题 ID 确定，所有受影响题的两个顺序都替换成修订版，不能选成绩较好的版本。

模型元数据文件指纹和全部权重分片的大小、修改时间与既有登记一致；没有重新计算全部大权重文件的内容哈希。原始输出、提示文本指纹、远端重新分词结果、本地汇总重建和独立 JSON 解析共同核验。

## 结果与数据释放

| 最终修订版（每题两个顺序） | P1 | Step120 |
|---|---:|---:|
| 新训练候选 | 12/32 | 14/32 |
| 新开发题 | 9/16 | 6/16 |
| 历史开发来源的保持 | 24/24 | 20/24 |
| 共享训练来源组的保持 | 15/16 | 16/16 |
| 合计 | 60/88 | 56/88 |

P1 相对 Step120 改对 10 次、改错 6 次。两种顺序都答对：训练为 4/16 对 5/16，开发为 3/8 对 2/8，保持为 19/20 对 16/20。选项顺序改变答案的题目分别有 9、13 道。两种顺序相关，不能把 88 次回答当成 88 个独立样本。

P1 的四项新训练分组分别为拣选 5/8、批量成本 0/8、串并行 2/8、运力 5/8；开发分别为 4/4、1/4、3/4、1/4。批量成本与条件组合仍值得优先处理。保持检查总体较好不代表每类均保持：共享来源组的持有成本仍新增错一次。

原版为 P1 59/88、Step120 53/88；原版与修订版都保留。修订由前提和措辞审核决定，未选择得分更高的版本。最终 P1 无无效答案，Step120 有一条空答案集合按原规则计错；闭卷输出均未截断。原版来源复核曾有一条截断，最终替换为明确库位的修订题后未截断，原始失败仍保留。

最终盲复核通过 **36/44**。另 8 道中，6 道真假布尔值与最终索引矛盾；2 道索引和布尔值自洽，但共享启动成本算错或运力逆推不成立。逐项来源审核、精确运算和构造枚举支持作者答案，操作者明确裁定保留原键，**没有把这 8 条模型失败改写成自动审核通过**。模型解释不作为训练答案文本。

全部 240 次输出已下载；四个远端运行汇总在本地重建一致，全部闭卷回答独立解析通过，最终两个模型的 88 对提示文本与 token 指纹一致。实际改变的四题均完整替换双顺序记录，其余 40 题逐字段保持。14 项相关测试通过。

[数据释放记录](cpt_remediation_release_20260917.safe.json)仅授权最终修订版的 **16 道训练题**。其余 28 道继续限定为开发/保持检查。冻结题包原先的待审标记保持不变，以单独的释放文件精确指定可训练 ID 和文件指纹。该决定是来源编写者的二次审核、模型异议和程序校验结合，不冒充外部独立专家认证。

## 下一阶段的固定范围

1. 仅使用最终释放的 16 道训练题，开发与保持题禁止进入训练。
2. 累计保留 P1 原有 315 条训练消息，计划加入 16 题各 3 次曝光，共 363 条；仍从 Step120 初始化，学习率 5e-7、一遍、批量 3，对应 121 步。实际序列与监督 token 数必须在训练器加载后另行冻结。
3. 保留 P1 的数据与配方并不等于预算相同：新增题会增加训练 token 和步数，不能把变化解释为严格等预算的单因素因果效果。
4. 训练后同时检查本轮开发/两类保持及原 P1 的迁移/保持结果，完整报告改对与改错。新题拟合或小型开发分数不能代替正式目标 196/226、1224/1446。
5. 本轮未证明 CPT 的增量价值，也未打开封存题。CPT 的配对比较仍属于后续问题。
