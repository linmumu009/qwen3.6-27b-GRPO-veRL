# 教材 QA 的百炼 API 试制（2026-09-07）

结论：完成200条候选，151条（75.5%）通过自动初筛，尚不能直接视为已人工验收的SFT训练集。停止扩大和训练，先抽查通过项及失败项，再决定是否改提示重做小样。

## 来源与边界

- 输入仅为获得用户用途授权的《The Handbook of Logistics and Distribution Management》第8版既有CPT JSONL，116条分块、44章。来源哈希见安全统计。没有重新独立核验授权条款。
- 在5号机调用百炼直连 `qwen3.8-max`；最小请求成功后，前4条串行作为接口和格式门禁，其余并发上限64。没有加载本地生成模型。
- 一条候选对应一个来源块和一个指定题型。按章轮转均衡取样，而非按评测错题选知识点。定义、比较、条件、应用各50条。
- 生成和内容审核都只接收教材片段及生成QA；不接收评测题、答案或既往诊断探针。审核器是同模型的新请求，不是独立专家。
- 本轮无训练、无权重选择；后续若训练，应仅考虑纯教材CPT分支，并保留Step120直接SFT对照，不使用曾训练评测题的分支。

## 检查与结果

| 互斥状态 | 条数 | 占候选 |
| --- | ---: | ---: |
| 自动通过、待抽查 | 151 | 75.5% |
| 结构/引用拒绝 | 32 | 16.0% |
| 内容审核拒绝 | 17 | 8.5% |
| 请求/解析失败、重复拒绝 | 0 | 0% |

32条结构拒绝均涉及引用不满足逐字匹配，其中1条也缺少问答字段（可能弃答）；这不等同于32条知识错误。17条内容拒绝中13条的支持性标志未通过，1条独立性未通过，此外非空问题列表也会阻止放行，各问题可重叠。不能把其余项自动认定事实正确。

通过项为定义41、比较38、条件36、应用36条，仍覆盖44章。该样本没有历史同口径趋势数据，不能据此推算扩大量后的通过率。

服务器内对冻结的1,672条评测题做归一化题面精确匹配、问答与评测题干/选项连续12词匹配，通过项命中0条。检查不发送任何评测文本到API；未验证语义近重复、翻译重合、书籍是否为评测来源。已有反复评测和模型选择历史，因此不能宣称独立盲测。

成功返回的生成与审核请求累计1,316,607输入tokens、50,859输出tokens，共1,367,466 tokens；另有最小连通测试18 tokens。不是费用账单，不含不可见服务端重试消耗。

## 下步门禁和风险

1. 高风险：同模型生成、自审可能共同忽略缺失条件或多余断言。建议人工分层抽查约20条通过项，以及若干拒绝项；来源正文与QA保持私有，不直接扩大。
2. 中风险：逐字引用受排版、换行影响，可能误拒。先复核拒绝项，再决定是否允许可追踪的空白归一化；不降低事实支持门禁。
3. 中风险：同块衍生QA相关性强。未来按来源章节/主题簇划分SFT训练与开发集，不随机拆分相邻改写；教材CPT已见过书籍，开发集并非未见知识测试。
4. 后续选择训练步数用独立开发集，正式评测不作为生成输入。当前`ready_for_training=false`，未导出自动可训练的messages数据。
