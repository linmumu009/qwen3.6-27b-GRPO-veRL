## 两种前文

- **来源前文**：原来源从标题到目标句之前的全部内容，目标句及后文不提供。
- **K既有前文**：固定K原提示回答的repeat 0正文，标题替换为同一准确来源标题。K和R都读取这份文本；R条件不能称为“R自身前文”。

保留原system/user问法，将前文置于assistant历史轮次，再添加同一条明确询问目标规则的user问题，要求一句话回答。两种条件的目标问题、参考答案、标题和推理参数相同；前文内容和长度不同。已有冻结评分及人工核对确认目标规则未在两种前文中完整提供；题目会提示主题，因此这不是闭卷独立迁移。

该设计将不完整前文变成历史对话，再进行明确追问。它不直接替换同一解码位置的token前缀，不能解释为已隔离自然生成路径的纯因果效应；前文的信息、措辞、长度仍共同改变。
