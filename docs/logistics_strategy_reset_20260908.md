# 领域适配路线重审与下一实验协议

日期：2026-09-08。状态：完成路线复查；下述新诊断与训练尚未执行。

## 决策

暂停继续打磨44组成对答案，不再把监督token相差5%或“最小修改”视作项目主目标。保留旧门禁实测，不回写失败为通过；旧方案改为备选机制实验。当前最有价值的问题是：**数据是否覆盖目标任务，模型究竟在哪个作答环节失败，以及CPT是否真是更好的SFT起点。**

目标仍是提升供应链问答，以LogistikaBench和SC-bench知识子集衡量，并保护已有Agent和通用能力；不擅自将目标改为RAG产品或完整工具调用提升。理论能支持可检验假设，不能保证下一轮训练达标。

## 从官方说明重新核对任务与来源

LogistikaBench官方卡说明它是允许多个正确选项的知识/推理评测，来源横跨MIT供应链概念、供应链运营、港口航道、国际商务及运输统计术语等，并明确提醒答案和分类可能有误。它并非为我们这一本物流管理教材设计。现有书可以贡献知识，但没有证据证明覆盖整套评测所需的技术细节。[官方数据卡](https://huggingface.co/datasets/berdymurad/LogistikaBench)

SupChain-Bench原论文同时评估领域知识与遵循业务流程的长链工具编排。我们的本地加载器只读取三个知识题文件，未包含工具题；必须继续称“SC-bench知识子集”。本轮不因此扩大项目去训练工具编排。[官方论文](https://arxiv.org/abs/2602.07342)、[官方仓库](https://github.com/Damon-GSY/SC-bench)

上述来源清单只用于界定能力范围，不是建议照着考题回溯原教材段落并生成近似训练题。任何新增语料应按预先确定的领域课程选取、独立生成与去重；网上可访问也不自动代表训练授权。历史记录载有用户对现有书训练授权的确认，不把早期审计的待确认状态误报成新阻塞。

## 下一步：一次有边界的无训练诊断

先完成现有私有逐题预测的**主题×候选数×单选/多选**交叉汇总；只输出计数、转移、解析率和哈希。无需新API请求，也不需要把题目交给外部裁判。特别核对305题与物料搬运的交集，当前证据未给出，不能把两个错误群体相加。

随后拟在5号机本地对冻结的96道诊断题做干预：48道269候选题、24道其他Logistika题、24道SC知识题，每层按纯CPT历史对/错各半抽取；若某格不足取全并披露，不用别层静默补齐。固定种子与ID后不换题。此分配用于机制识别，不估计总体错误比例；分层分别报告，不把96题简单平均称总体准确率。

两个模型均测：Step120、纯教材CPT4x116。不加入新SFT检查点，不按官方分数选模型。第一阶段只使用以下三条件，每条件三次，最多96×2×3×3=1728次本地请求：

1. 冻结原协议，建立本轮对照。
2. 保留题干和全部候选内容，仅确定性打乱选项并映射回原索引。不可删干扰项、不可依答案排序。测排列敏感性，而非“缺知识”。
3. 保留全部信息，增加固定的逐项判断/核查否定词与多选完整性的作答指引，给足输出预算；最终仍用原答案集合严格评分。另报成本、截断及解析失败。此条件同时改变指引与计算预算，定位为整体作答策略干预，不宣称隔离了纯推理能力。

第二阶段只对仍稳定失败的题审查证据充分性。区分“资料明确支持”“资料不足”“歧义/缺图/疑似答案问题”，后两类保留官方评分但不作能力归因。检索/证据编写不得读取金答案；先检查是否足够判断相关选项，不能只提供结论。只有来源支持充分的子集才比较闭卷与带证据表现，报告所有未覆盖项。此阶段需先界定正文复核范围；旧轮最多8题的授权不能无限沿用。本协议不授权外发官方题或自动生成其解释。

预算封顶：第一阶段上述1728请求后做路线决策，不因无提升反复改提示刷题。无有效差异也有结论：停止把排列或提示优化当主线。样本小或多机制并存则报告不确定，不硬分为“知识/推理”二选一。三次重复不当作三个独立题目。

## 诊断结果如何改变下一轮训练

| 信号 | 优先路线 | 不能直接推出 |
|---|---|---|
| 排列/作答策略明显改变同题结果 | 用独立来源构造选项辨析、否定边界、多选完整性和长候选表匹配的SFT样本 | 不是仅需JSON格式SFT；历史正常运行解析本已接近或达到100% |
| 充分外部证据稳定救回，而原书没有覆盖 | 多来源补知识，再比较直接QA-SFT与必要时CPT | 开卷救回不证明模型预训练没见过；RAG只作为诊断或另行选择的产品路线 |
| 证据充分仍失败，分解步骤有帮助 | 训练来源可验证的规则应用/条件判断/计算过程 | 不直接上RL；先要可信可验证答案与稳定任务定义 |
| 题目缺信息、答案存在争议 | 保留官方原分并单列局限，避开按争议金答案训练 | 不通过删除难题抬高官方分数 |

数据组织单位改为“一个可验证知识或规则及其适用条件”，而不是凑2000条问答。每组至少覆盖直接问答、易混概念/反例、条件应用；必要时再增加长候选表形式。保留简洁但足够的理由，不强制长思维链。来源分组隔离训练与开发，测试题及其改写、针对其答案反向组织的内容一律不进入训练。

一旦独立小样本能区分目标能力，下一轮训练使用同一批新数据、同样训练协议比较 **Step120→SFT** 与 **纯CPT→SFT**，并保留两个未训练起点。这样才能判断CPT前置是否有增益。若预算只能支持一臂，先明确无法回答前置CPT的因果价值；不默认CPT最优。LoRA、全参数、RL、增加轮次都暂不做大网格搜索。

## 成功与止损

开发集用于预先固定的数据/训练选择；两套官方知识集分别报告最终结果及得失题数，已反复观察的官方集不能重新称为未见测试。保留早期+3个百分点作为待重新确认的工程目标，不称为理论阈值或用户最新明确指定目标。Agent及开源能力独立回归未补齐前，任何新模型都不替换交付模型。

本轮完成的是证据核对与实验优先级重排；没有生成训练数据、调用百炼或启动训练，也没有执行上述1728请求。公开数据卡页面会自动展示示例，本轮不将这些示例用于构造训练内容；私有题目、教材和模型回答未外发。下一项执行工作已具体限定为现有预测交叉汇总，而不是继续给44题增加门禁。
