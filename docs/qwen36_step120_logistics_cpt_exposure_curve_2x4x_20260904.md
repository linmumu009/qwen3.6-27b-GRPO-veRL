# Step120 单书 CPT 2遍/4遍曝光曲线复核

日期：2026-09-04
对象：`qwen3.6-27b-step120` → `handbook8e-cpt-2x` / `handbook8e-cpt-4x`

## 结论先行

**不建议交付 2遍或4遍候选，也不建议继续把同一本书原样训练更多遍。**

这次实验把“上次一遍 CPT 是否只是训练量太小”拆开验证了。2遍与4遍都让模型显著更贴近书籍原文：固定书内 NLL 相对 Step120 分别改善 `2.445%` 和 `4.126%`，均通过预先设定的 `2%` 吸收门槛；全权重差分也确认语言模型参数发生了比一遍更大的更新。这说明训练链路、梯度和检查点都真实有效。

但交付需要的知识问答没有随之提升：独立改写书内题三者均为 `189/200`，逐题没有任何翻转；SC-bench 三者均为 `189/226`；全量 SC-bench + LogistikaBench 三轮多数票中，2遍比 Step120 少 3 题，4遍只多 2 题，分别为 `-0.1794` 与 `+0.1196` 个百分点，均远低于 `+3.0` 点晋级线且统计上不能区分于零效应。

因此，现象不是“没有学到书”，而是“学到了书的文本分布，却没有把它转化成新的闭卷物流问答能力”。继续重复同一原始文本，最可能继续降低 NLL，而不是解决知识覆盖和问答利用问题。

## 训练是怎么做的

本轮不是分别独立训练两个模型，而是做了一条连续的 4遍曝光曲线：

- 从同一个 Step120 模型态开始，初始化一套 fresh Adam；不恢复旧 optimizer/RNG。
- 每遍包含 116 个不超过 4,096 token 的书籍块，全局 batch 为 4，因此每遍正好 `116 ÷ 4 = 29` 个 optimizer step。
- 每遍处理 336,702 个含 EOS 的 sequence token；第 58 步累计 673,404 token，对应 2遍；第 116 步累计 1,346,808 token，对应 4遍。
- optimizer 从第 1 步连续运行到第 116 步，第 58 步不重置，避免“2遍模型”和“4遍模型”之间混入优化器重启效应。
- 学习率在两步有效预热后，沿整条 116 步曲线按余弦从峰值 `5e-7` 衰减到 `1e-7`；视觉编码器和 MTP 不训练。
- 仅在第 58/116 步保存模型与 extra 状态，不保存 optimizer；两个 Megatron 检查点均为 32 个分片、54,720,369,973 bytes。

每遍平均训练 loss 为 `2.0447 → 1.9702 → 1.9233 → 1.9165`。第四遍相对第三遍只再下降约 `0.0068`，已经出现明显边际递减。首遍出现的最大裁剪前梯度范数为 `117.20`，后续三遍最高仅 `8.05 / 9.13 / 7.13`；全程无致命日志。

两个 HF 导出均通过严格完整性检查：各 15 个 safetensors 分片、56,484,503,104 bytes、1,199 个 tensor、64 个语言层，无 missing/extra/shape/dtype mismatch；15 个冻结 MTP tensor 从 Step120 回填。

| 测试 | Step120 | 2遍 CPT | 4遍 CPT | 判定 |
|---|---:|---:|---:|---|

| 书内改写知识题 | 189/200 | 189/200 | 189/200 | 两者都是 0 道改对、0 道改错，未通过 +1.5 点门槛 |
| SC-bench knowledge | 189/226 | 189/226 | 189/226 | 逐题正确性完全不变 |
| LogistikaBench 三轮多数票 | 1,180/1,446（81.604%） | 1,177/1,446（81.397%） | 1,182/1,446（81.743%） | 2遍净减 3 题；4遍净增 2 题，均为噪声量级 |
| 两公开集三轮多数票 | 1,369/1,672（81.878%） | 1,366/1,672（81.699%） | 1,371/1,672（81.998%） | 4遍仅 +0.1196 点，McNemar `p=0.754`，未通过 +3 点门槛 |
| 全权重差分 | 基线 | 10.04% 元素变化；相对 L2 `2.13e-4` | 12.59% 元素变化；相对 L2 `3.08e-4` | 参数更新真实且随遍数增大；视觉与 MTP 均为 0 变化 |

固定 NLL 的配对 bootstrap 95% 区间分别为 `[-0.05762, -0.05102]`（2遍减 Step120）和 `[-0.09573, -0.08722]`（4遍减 Step120），所以“模型更会预测书里的文字”是确定结论。4遍相对2遍又改善 `1.723%`，但这种继续吸收没有映射到问答增益。

公开评测采用同一个冻结的 1,672 题输入、TP8×DP1、BF16、温度 0、同 seed 三轮运行，再按每道题解析答案做严格多数票。2遍三轮准确率为 `81.818% / 81.699% / 81.699%`；4遍为 `82.057% / 81.938% / 81.758%`。4遍有 2 道题三轮没有形成严格多数答案，按错误计分。少量跨轮抖动说明单轮多一两题不能作为晋级证据。

## 逐字记忆检查

对 32/64/128-token 前缀各使用同一批 200 条私有原文续写：

- Step120 最长连续命中为 `8 / 11 / 15` 词。
- 2遍和4遍最长连续命中均为 `6 / 11 / 15` 词。
- 2遍与4遍都没有新增任何候选独有的 10 词或 20 词连续复现。

因此，本轮没有观察到新增长片段机械背书报警；这只能说明固定探针未发现强逐字复现，不能证明模型不存在任何形式的记忆。

## 为什么在这里停止后续门禁

原门禁是顺序执行：先证明吸收，再证明独立知识增益和公开基准的实用提升，只有候选仍可能晋级时才运行通用能力与原 Agent 回归。2遍和4遍虽然通过 NLL 门槛，但都未通过独立知识题 `+1.5` 点和公开基准 `+3.0` 点门槛；通用/Agent 回归无论结果如何都不能把候选变成可晋级模型，因此本轮没有继续消耗算力运行它们。这不是漏测，而是按预登记顺序门禁早停。

## 下一步建议

1. **停止同一本书的第 5遍及以后原样 CPT。** 现有曲线已经覆盖“剂量不够”的主要疑问：参数变化和书内 NLL持续增加，但问答能力不动。
2. **交付侧使用 RAG。** 把已授权书籍和企业物流资料做可追溯切块、检索与引用，先解决知识可用性和更新性；需要时只用少量 SFT 固化引用格式、拒答边界与工具行为。
3. **若继续做参数化知识训练，改成多来源混合。** 至少准备 5M 个去重领域 token，单本书不超过领域数据的 10%，加入 10%–20% 通用回放，并覆盖运输、仓储、采购、供应链计划、履约、逆向物流等不同来源和文体。
4. **增加“知识利用”样本，而不只增加原文。** 从授权资料构造需要比较、计算、约束判断、案例决策和证据定位的训练样本；答案由物流专家抽检或复核。可在多来源 CPT 后接一轮小规模高质量 SFT，但不要把未经验证的自生成问答直接当金标。
5. **重做更有分辨率的隐藏评测。** 当前书内探针由 Step120 参与生成且基线已达 94.5%，天花板过高；下一轮应由独立模型/专家出题，保证训练资料可回答、与训练文本无逐字泄漏、Step120 基线仍有足够错误空间。
