# Qwen3.6-27B Step120 物流知识 Stage 0 实测与训练决策

日期：2026-09-03

## 结论

**Step120 在物流知识上没有退化，但也没有达到可交付的新增垂域能力幅度；当前不应直接开始单书 CPT 或评测题型 SFT。**

同机、同 vLLM、同精度和同提示词的主比较中，Step120 相对原生权重总准确率从 `81.52%` 到 `81.88%`，仅提升 `0.36` 个百分点；1,672 题里有 6 题由错变对、0 题由对变错。这个方向是一致的，但远低于训练前登记的 `+3` 个百分点实用晋级门槛，不能表述成“Step120 已获得物流垂域知识”。

这也回答了下一步的路线问题：现有模型可以作为新阶段初始化权重，但没有证据支持把一本约 37 万 token、且训练权尚未确认的书直接重复若干轮。更合适的是先补独立隐藏评测和多来源授权语料，再决定是否做 5M-token 混合 CPT 金丝雀；短期交付优先比较 RAG，知识利用问题才考虑短 SFT。

## 实测结果

主比较使用 5 号机本地原生 Qwen3.6-27B 与 Step120 HF 导出，二者均通过同一个 Ascend vLLM 镜像，以 BF16、TP4×DP2、`temperature=0`、关闭 thinking、并发 64 运行。

| 范围 | 本地原生 | Step120 | 变化 | 0→1 | 1→0 |
|---|---:|---:|---:|---:|---:|
| LogistikaBench（1,446） | 81.26% | 81.60% | +0.35 点 | 5 | 0 |
| SC-bench 知识题（226） | 83.19% | 83.63% | +0.44 点 | 1 | 0 |
| 合计（1,672） | 81.52% | 81.88% | +0.36 点 | 6 | 0 |

合计配对 McNemar 精确检验 `p=0.03125`。这是 6 个 discordant item 全部同向产生的统计信号，但绝对幅度只有 0.36 点，而且来自公开评测；它不能替代预登记的实用幅度门槛、独立隐藏集或重复运行。

类别宏平均从 `87.58%` 到 `87.72%`，只增加 `0.15` 点。SC-bench 中存在样本数为 1–4 的类别，因此这个未加权宏平均波动较大，决策应以逐数据集分数和逐题转移为主。

## 部署差异敏感性检查

百炼 `qwen3.6-27b` 得分 `81.70%`，本地同名原生权重得分 `81.52%`，相差 `-0.18` 点；逐题却有 15 个 0→1 和 18 个 1→0，`p=0.728`。百炼原生与 Step120 的总差值同样只有 `+0.18` 点，且为 16 个 0→1、13 个 1→0，`p=0.711`。

因此，当模型差异只有零点几个百分点时，不能混用百炼与本地 vLLM 直接归因训练；同机同栈结果才是本轮主证据。百炼结果仅说明当前交付环境下两者总体接近。

## 评测口径与数据质量

- 冻结 LogistikaBench 1,446 题和 SC-bench 知识题 226 题，共 1,672 个唯一 item hash；输入 SHA256 与本地文件复核一致。
- 所有题统一要求输出零基选项下标 JSON，并按答案集合完全一致评分；有效三次全量运行最终 API 失败与解析失败均为 0。
- LogistikaBench 有 305 题共享 269 个选项的长匹配池，占 21.1%；该组本地原生/Step120 为 `68.85%/69.51%`，贡献 2 个净提升。它更接近大候选表匹配，不应与普通 2–12 选项题混为一种能力解释。
- LogistikaBench 有 1 道单选项题，天然缺乏区分度，但为保持官方分母未删除，已单独标记。
- SC-bench 有 8 道判断题未显式提供选项，按题型规则重建为 `[true, false]`；该规则有回归测试。
- SC-bench 另有 100 道工具题，不属于本轮闭卷知识评测；本轮不能替代现有 Agent/工具门禁。

第一次 Step120 全量运行曾出现 `1,669/1,672` 解析失败，但 API 全部为 200。抽查确认 vLLM 模板仍开启 thinking，128 个输出 token 全部进入隐藏思考字段，最终 content 为空；该运行已废弃，不用于模型能力结论。显式关闭 chat-template thinking 后，8 题协议探针 8/8 可解析，随后全量解析失败为 0。这一事件说明后续评测必须把推理模板配置作为强制门禁。

## 训练决策

### 现在不做什么

- 不使用 LogistikaBench 或 SC-bench 的错题、改写题或答案解释反向制训练数据；否则下一次公开分数失去独立性。
- 不把《The Handbook of Logistics and Distribution Management》第八版整本重复多轮做 CPT；其正文约 37 万 token，规模不足，且文件版权页要求 AI/ML 训练取得事先书面许可，目前未见许可证明。
- 不为输出格式做 SFT；正确关闭 thinking 后三端解析率均为 100%，不存在需要训练修复的格式问题。
- 不把 `+0.36` 点包装成垂域知识提升；本轮实用门槛未通过。

### 下一步最合适的顺序

1. 新建 300–500 道按来源文档隔离的隐藏物流知识题，覆盖运输、仓储、物料搬运、采购、库存、供应链计划、履约协同、海关/法规；不复用两个公开 benchmark 的题面或来源段落。
2. 先做 RAG 基线，判断剩余 303 道两模型共同错题所代表的缺口是否能被可靠检索解决。短期交付如果要求“马上懂物流”，RAG 的投入/风险比最高。
3. 若隐藏闭卷解释题仍显示真正知识缺口，建设 20M–50M 去重后的多来源授权物流语料；Wikipedia 只补概念广度，需和开放政府/国际组织资料、企业自有文档及一般能力回放组合。
4. 从 Step120 model-only 权重初始化全新 Adam，先做 5M-token 混合 CPT 金丝雀，而不是精确恢复旧 GRPO 优化器；随后仅在“知道但不会调用知识”时增加短 SFT。
5. 每个候选同时复测物流隐藏集、两套公开知识集、SC-bench 工具题、原 Agent 密封集和开源密封集。物流知识至少 `+3` 点且其他能力不下降超过 `1` 点才晋级。

如果后续提供该书的书面训练授权，它可以作为多来源语料中的一个骨架来源，最多曝光 1–2 次；仍然不能单独承担 27B 模型的领域继续预训练。
