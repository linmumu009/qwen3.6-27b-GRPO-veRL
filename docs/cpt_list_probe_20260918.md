问题在三个长度下完全相同；各长度只取同一干扰项序列的前缀，形成嵌套集合。移动正确项时维持其他候选的相对顺序。192种提示统一打乱一次，随后三遍复用同一批次顺序。每模型temperature0、seed20923、thinking off、TP8、BF16、eager，输出最多96 token，窗口8192，每批8，max_num_seqs16。

原样查找故意在题面给出正确术语，用于观察检索位置及索引输出；它不是闭卷知识成绩。该模式及概念模式全部只作评估，禁止自动进入训练。

## 事前判读规则

1. 每模式、长度报告96次调用得分，并单列四个答案位置；以8个概念为语义单位，不把重复调用当作独立知识样本。
2. 分别比较4→32、4→128的同概念/模式/相对位置/重复序号得失。列表长度增加同时改变干扰项数量与内容；不能声称纯token长度因果效应。相对位置相同不等于绝对索引相同。
3. 同一提示三次输出是否变化单列；仅能评估本次固定批次、同进程中的波动，不能替代跨机器、跨重启或不同批次的稳定性测试。
4. 若原样查找也下降，优先检查索引对应及列表处理；若只有概念模式下降，优先检查增加干扰项后的概念区分。短列表稳定错误仍需复核歧义和知识，不能仅凭错误认定知识缺失。
5. 若全部接近满分，说明这个小试没有复现缺口，不支持立刻做索引训练；应扩大来源独立、相近概念的区分难度，再决定训练干预。不能把阴性结果外推为269选项正式题不存在格式影响。

本轮只覆盖8个较熟悉概念、单个异质词表，最大128选项，不能解释P4正式回退或代表全部物料搬运知识。保持P1为参考，不按本小试自动选择或提升模型。

### 这轮改变了什么判断

本结果不支持把“候选列表变长或索引超过100，本身就导致P4失效”作为下一轮训练依据。在本小试的熟悉概念、候选集合和运行条件下，没有观察到该缺口；它不是对269选项正式任务的排除性证明。

三个模型全部达到满分，测量无法区分它们。8个概念较熟悉，很多新增干扰标题与目标差异明显；增加列表长度没有形成足够的概念区分难度。因此，这轮是一个边界明确的阴性诊断，**不是性能提升，也没有解释P4为何回退**。此前269选项组少对7题仍是待解释现象，不能倒推本次结论为“格式无关”。
