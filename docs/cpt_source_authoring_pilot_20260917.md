## 2. 同模型复核漏掉了什么

- 仓库角色可以兼容，不能因符合混合中心就否定同时具有配送中心职能。
- 多道题在题干给出核心规则或答案维度，闭卷作答实际变成照抄。
- 一般搬运成本趋势不能无条件推成每个情境的必然总成本排序。
- 桥梁题混淆水下吃水与水上高度，且未给出关闭状态净空，无法推出必须等待开桥。
- 减少载荷后“需要增加航次”不等于“已经恢复吞吐”；原解释把必要条件读成既成结果。
- 普通箱子或板加网装上飞机，不足以建立其航空集装器身份。
- 唯一开发题仍是两个容量相加，不能仅因写成日志就算新推理结构。

以上为 Codex 操作者对归档来源及题目的逐项审阅，不是外部专家或人类裁定。5个可留素材也包含浅层定义应用，不能代表迁移能力或广域保持。[完整逐项记录与可复算计数](cpt_expansion_draft_audit_20260917.safe.json)。
