# Qwen3.8 Step70：v15/v20/v21困难留出集最终结果

## 结论

Qwen3.8-27B的70步GRPO训练后模型已完成v15、v20、v21全部1,430道困难留出题评测。三机监督器及各队列退出码均为0，三机共48张NPU已释放，未留下vLLM worker。

在与原生Qwen3.8完全相同的题目和采样合同下，最多6条轨迹的任务通过数由`2/1,430`提高到`18/1,430`，相对为9倍；绝对通过率由0.14%提高到1.26%。这说明训练产生了方向一致的困难集恢复，但绝对能力仍低。

## 可比性与边界

- 三个版本均用跨主机合并后的三组无序256位聚合指纹核对题目集合，原生与Step70逐版一致。
