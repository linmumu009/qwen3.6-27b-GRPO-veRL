# Qwen3.8 Step70 训练后留出评测安排

日期：2026-08-18

## 结论

正式训练第一次端到端运行在第4步因单条超时轨迹缺少 rollout log-prob 中止；旧外层错误地把异步队列终止记录为成功，但没有完整 Step70 checkpoint。训练后评测监督器拒绝了该伪成功，未生成任何留出集轨迹。修复后的正式训练从原生 Qwen3.8-27B 重新开始，训练和评测两层均以完整 Step70 checkpoint 作为不可绕过的成功门。

## 留出集

- 原始范围：v15、v20、v21 各500题，共1,500题。
- 精确排除训练题：v15 12题、v20 39题、v21 19题，共70题。
- 留出集：v15 488题、v20 461题、v21 481题，共1,430题。
- 70个训练 identity 全部在原始1,500题中一一命中；排除后的训练交集为0。
- 5号机与6号机各715题，并按难度层平衡。

## 自动执行顺序

1. 等待修复后的正式训练监督器正常结束并完成 Ray 清理。
2. 强制训练保存 Megatron distributed model checkpoint，并验证训练目录仅发布完整 `global_step_70/actor`、model metadata 与分片；Step4、PP2不完整在线HF导出、部分保存或错误退出均停止。
3. 从 Step70 Megatron checkpoint 严格导出 HF 模型，验证1199个基座tensor的名称、形状、层覆盖与分片完整性。
4. 对导出模型逐文件计算 SHA256，复制到6号机后逐文件复验。
5. 再次验证留出分片行数、训练交集和SHA256。
6. 5/6号机分别启动独立16卡 TP4×DP4 推理集群，每副本并发16；两机并行、每机按 v15→v20→v21 顺序运行。
7. 每题先采2条；已有至少一条正确和一条完整错误时停止，否则再采2条，最多6条。结果保持禁训、禁发布，完成后仅输出安全聚合。

推理配置保持原Qwen3.8采样口径：`reasoning_effort=medium`、`temperature=1`、`top_p=.95`、`top_k=20`、4,096 prompt + 90,112 response = 94,208 tokens，30分钟超时覆盖排队、生成和工具执行全过程。

## 失败关闭

训练返回0不再等同于训练成功；Step70 checkpoint、导出manifest、跨机模型SHA256、留出集零交集和两机分片SHA256必须全部通过。任何一门失败，评测保持停止并写出失败状态，不会退回Step4模型、原生模型或部分留出集继续运行。
