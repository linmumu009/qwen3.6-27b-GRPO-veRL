# CPT 语料分块、知识关联与重复曝光技术报告

日期：2026-09-08

文档版本：1.0

对象：Qwen3.6-27B Step120 后的物流领域继续预训练（CPT）

性质：实现复核、技术讨论归纳与待验证实验设计。本报告未修改训练程序、未生成新训练语料、未启动新训练。

## 1. 核心结论

本轮讨论关注：有限长度的训练序列是否会切断物流知识关系；重叠切块和每遍改变切法能否改善；重复曝光是否造成过拟合。

1. **分块限制当次预测可见的上下文，但不等于知识永久隔离。** 各文本块共享模型参数，分别学到的事实可能在回答时组合，但组合没有必然保证。
2. **文档结构完整不等于知识关系完整。** 按段落和章节切块可以减少排版结构破坏，不能保证定义、条件、例外、指代及跨章节关系完整。
3. **本次书籍 CPT 使用固定、无重叠切块。** 44 章正文形成 116 条记录，每条末尾补一个 EOS，最大训练序列长度 4,096 token；四遍训练没有每遍重新切块。
4. **重叠和移动边界可以提供新的局部上下文，但不是跨块记忆机制。** A/B 重叠、B/C 重叠，不代表训练 C 时能访问整个 A。
5. **不同切法不等于新增知识。** 同一本书重复四遍仍然是重复曝光；可能改善关系覆盖，也可能过度适应原文。
6. **现有证据不能证明切块是问答收益有限的主要原因。** 应通过预算受控实验分别检测事实吸收、跨边界关系和远距离组合。

本文中的优化方法属于实验建议，不能表述为已经验证有效的工程能力或交付收益。

## 3. 当前数据和训练实现

### 3.1 来源与清洗

使用《The Handbook of Logistics and Distribution Management》第八版的私有 TXT。制数入口读取 `book.txt`，并非将 PDF 页面图像直接送入模型。

正文范围从 `PART ONE` 到 `REFERENCES` 之前，覆盖 7 个部分、44 章；排除扉页、目录等前置材料及末尾参考文献和索引。保守删除高置信页码、重复页眉，整理项目符号，修复部分排版断行，不激进删除图表相关文本。图表仅可能以 TXT 中已提取的文字形式参与。

安全清单记录：去除 693 行页码、375 行重复页眉，转换 2,001 个项目符号，得到 4,685 个基础文本块。这些段落、标题或列表片段还不是最终训练记录。[R1][R2]

### 3.2 如何切成 116 条训练记录

程序按原顺序拼接基础块，以空行分隔。部分或章节变化就结束当前记录；同章内若加入下一段会超限，则开启新记录；仅当单个基础块本身超长时，按 token 切开。没有重叠窗口，没有根据跨章节语义依赖重新编排。

| 指标 | 实际值 |
|---|---:|
| 训练记录数 | 116 |
| 正文内容 token | 336,586 |
| 每条末尾加 EOS 后的序列 token | 336,702 |
| 最大正文记录 | 4,095 token |
| 最大训练序列 | 4,096 token |
| 最短正文记录 | 5 token |
| 正文少于 1,024 token 的记录 | 16 |

4,096 是上限，不是固定长度。章节尾部和结构性标题可能形成短记录。后续实现应明确以 `最大序列长度－EOS预算` 作为正文上限：制数函数默认参数不等于最终输入保证，仍需用训练 tokenizer 检查加 EOS 后的长度。[R1][R2][R3]

### 3.3 存储字段与模型可见内容

私有 JSONL 每行一条记录，再转为 Parquet。字段包括 `text`、记录编号、部分/章节、原文行号、token 数、正文哈希和源文件哈希。

模型只读取 `text`。章节元数据、行号和哈希不会自动进入上下文；正文里实际保留的标题会参与训练。元数据用于追溯和校验，不能替代语义连接。[R2][R4]

### 3.4 监督目标与 batch

工程复用 veRL 的 `sft_trainer`，但自定义数据集执行原文 causal-LM 训练：不套聊天模板，不构造 user/assistant，不只监督答案。

对 `t1, t2, …, tn, EOS`，监督关系为：

```text
t1             → t2
t1 t2          → t3
……
t1 t2 … tn     → EOS
```

这是目标关系示意；实际训练可并行计算各位置，不是逐 token 自由生成。加载器屏蔽首 token 对应的目标掩码，以配合训练器移位，避免末位置绕回预测首 token；其余真实目标包括 EOS 受监督。数据集层采用 `no_padding`，超长报错而非静默截断。[R3][R5]

**batch=4 表示四条记录共同贡献一次参数更新，不表示用前四块预测第五块。** 同属一个 batch 不会自动建立共同注意力上下文。

### 3.5 曝光量

| 实验位置 | 累计遍数 | 更新步数 | 累计序列 token，含 EOS |
|---|---:|---:|---:|
| 独立单遍实验 | 1 | 29 | 336,702 |
| 后续连续曲线中间点 | 2 | 58 | 673,404 |
| 后续连续曲线终点 | 4 | 116 | 1,346,808 |

每遍为 `116 / 4 = 29` 次更新。独立单遍与后续四遍曲线不是同一条优化器轨迹；后者从 Step120 模型态重新开始，初始化新优化器，在第 58/116 步保存。四遍内重复固定切块，未混入 Agent 轨迹和通用回放。单遍入口没有从 116 条中划出训练过程验证集。[R6][R7]

## 4. 分块会破坏什么结构

至少需要区分三层：文档的章节段落结构；事实之间的定义、条件、例外和实体依赖；参数中形成的知识表示。分块直接改变输入呈现及同次预测可见的语义依赖，对参数知识造成多大影响则需要测量。

以下为虚构物流规则，仅用于说明机制：

```text
前文：A 类货物通常适用规则 R。
后文：但当运输时间超过 T 时，这类货物必须改用规则 S。
```

后文若独立成块且缺少“这类货物”的指代，模型当次预测就无法直接利用前文确定适用范围。全部文字进入训练，不代表完整条件关系都获得直接监督。

| 切断对象 | 风险 | 可能的改法 |
|---|---|---|
| 句子前后部分 | 局部句意不完整 | 按完整句段切分 |
| 定义与解释 | 术语缺少背景 | 保留必要定义 |
| 规则与例外 | 规则过度泛化 | 尽量共同呈现并明确条件 |
| “上述”“这种情况” | 主体不明 | 依据来源展开指代 |
| 跨章节事实 | 缺少组合训练机会 | 关联说明、案例或组合问答 |

“不跨章”可以避免随意混杂主题，却不能证明语义完整，因为知识依赖本身可能跨章。当前程序保护了部分文档结构，没有执行知识依赖完整性检查。

## 5. 第1块与第4块能否在参数中建立联系

假设：第1块说明“X 属于 A 类”，第4块说明“A 类需要 M”，考试询问“X 需要什么”。两个事实可分别学进同一套参数，模型可能在回答时提取并组合；并非必须在训练中见过完全相同的问题。

但成功需要至少四项条件：事实一被学到、事实二被学到、问题触发正确提取、组合时不丢失条件。分别答对两道事实题，不代表组合题必然答对。若第4块只写“上述货物需要 M”，则主体本身已缺失。

受控研究显示，事实提取与比较、分类、逆向查询等知识操作可以有不同表现，支持将“存储/提取”和“操作/组合”分开测量；它不能直接证明本项目错误由切块造成。[P1]

即使同块共现，也受因果方向约束：后面的 token 能关注前文，前面的 token 不能关注未来文字。共同出现增加机会，不等于所有方向的问答关系都受到了充分训练。

因此，稳妥表述是“可能存在知识关系学习缺口”。不能仅从分块推断“原来已有的知识体系被破坏”；若旧能力下降，还需检查遗忘、训练强度、分布变化与评测波动。

## 6. 重叠切块的机制与边界

### 6.1 如何提供前文

```text
块1：[A 的正文及尾部]
块2：           [A 的尾部][B 的新正文]
```

预测 B 时能利用 A 的尾部，适合修补相邻段落的指代、定义延续和因果解释。重叠长度需要结合语义单元和计算预算选择，本次没有实测最佳比例。

可比较两种监督方式：重叠与新内容均计算损失；或重叠仅提供上下文，主要监督新内容。后者减少重复目标，但仍消耗输入长度和计算，且前缀仍可能通过后续目标的注意力影响梯度。它需要修改当前掩码，并按实际 token 边界和训练器移位规则验证，不能仅按字符数屏蔽。

### 6.2 为什么不能恢复整本书的上下文

当前独立样本不保留上一块的完整状态。A/B、B/C 分别重叠，不会让 C 直接看见整个 A。超过窗口的远距离事实仍不能靠局部重叠共同出现。

RAG 的重叠主要提高检索片段完整性，最终取决于必要证据是否被共同检索；CPT 的重叠改变训练时的预测条件。两者都不自动恢复全部知识关系。

此外，EOS 是结束标记，不天然等同于 attention 隔离。把多个片段拼进同一序列时，是否跨片段关注取决于实际 attention mask；不能用“插了 EOS”代替这项检查。

## 7. 每遍换一种切法是否有价值

可以实施。最有价值的变化是让旧边界两侧在新序列里共同出现：

```text
原段落： A  B  C  D  E  F
第1遍：[ A B ][ C D ][ E F ]
第2遍：[ A ][ B C ][ D E ][ F ]
```

第二遍增加 B→C 和 D→E 的上下文覆盖。若仅把四块各自再切一半成为八块，没有跨过旧边界，就未修复旧边界，反而缩短了上下文。

| 变化方式 | 潜在收益 | 限制 |
|---|---|---|
| 单纯细分 | 增加短片段 | 不保证新增关系覆盖 |
| 相近长度移动边界 | 修补旧边界 | 受最大长度约束 |
| 长短块混合 | 局部与背景兼顾 | 计算和更新预算需控制 |
| 每遍确定性改变切点 | 可复现地减少固定边界依赖 | 不增加新事实 |
| 组合远距离相关段落 | 提供关系训练机会 | 需验证来源、语义和顺序 |

不建议任意打乱段落：规则、例外、指代可能依赖顺序。应在完整段落边界中选切点，保存每遍种子、切点、来源区间和哈希。更长上下文能容纳更远关系，但研究表明窗口内的信息也不总被稳定利用，因此增大窗口不是充分条件。[P2]

## 8. 重复曝光与过拟合

### 8.1 重复不等于已经过拟合

同一语料可以训练多遍，第一遍学习不足时后续曝光可能有效。变化切法可以减少对固定前缀、边界的依赖，但主体事实和措辞仍反复出现，不能算四倍独立知识量。

| 观察 | 能说明什么 | 不能直接推出什么 |
|---|---|---|
| 训练 loss 下降 | 更会预测训练文本 | 问答必然提高 |
| 原文 NLL 下降 | 更贴近书中文字分布 | 已有完整知识体系 |
| 独立问答不变 | 暂无任务收益 | 已证明过拟合 |
| 训练改善、独立表现持续恶化 | 过拟合的重要信号 | 唯一原因是切块 |
| 通用/Agent 下降 | 可能遗忘或分布偏移 | 与原文记忆完全等价 |

历史四遍曲线中原文拟合改善没有对应清晰问答增益，这不足以单独证明过拟合，也不能证明换切法一定有效。[R7]

### 8.2 必须分开的预算口径

- 唯一来源内容量：去重后正文规模。
- 输入 token 量：包括重复前缀、分隔符和 EOS。
- 监督目标 token 量：实际 loss mask 非零的目标数。
- 原文位置曝光分布：各段落或位置作为输入、作为目标出现几次。

改变切法后，重叠、重复标题和额外 EOS 都会改变统计，应依据实际 tokenizer 和掩码计数。屏蔽前缀目标不等于前缀没有计算成本或训练影响。

在忽略首尾和语义边界的理想定长窗口情形，窗口长 L、重叠 O 时，输入量相对无重叠约增加到 `L / (L - O)` 倍。这是成本估算，不是本书实测。

## 9. 建议的受控实验

### 9.1 假设与组别

H1：固定边界使部分相邻关系缺少完整上下文，移动边界可以改善这些关系题。H2：重叠前缀有收益，且不能完全用额外曝光解释。H3：远距离关系需要显式关联材料或知识使用监督，局部移动边界不足。

| 组别 | 数据方式 | 检验内容 |
|---|---|---|
| A | 重复原固定切块 | 基线 |
| B | 保持顺序与相近长度，每遍移动边界 | 新边界覆盖 |
| C | 重叠前缀，明确损失掩码 | 前文补充 |
| D | 增加有来源依据的关联说明 | 远距离关系直接呈现 |

优先比较 A/B。C 需要新增并验证掩码逻辑；D 改变内容和监督关系，必须独立解释，不能称作纯切块效应。若使用答案专属 SFT，还同时改变了训练目标，需要额外对照。

### 9.2 公平比较不能只固定 step

改变块数后，同样 batch 和 step 不代表相同内容曝光；固定四遍也不保证重叠组输入量相同。应预先登记主要口径：

1. 尽量匹配原始正文的监督曝光，并单列 EOS 等额外目标。
2. 同时报总输入、有效监督 token、长度分布、更新步数和计算时间。
3. 尽量匹配每次更新的有效 token 预算，必要时调整梯度累积。
4. 学习率按共同预算进度对齐；更新步数不能匹配时明确混杂因素。
5. 若主张计算效率，另外开展相同计算预算比较。

各组从同一 Step120 模型态开始，优化器、长度上限和评测协议尽量一致。可用资源允许时重复种子；否则明确探索性质，不将单次微小差异当稳定结论。

### 9.3 分层评测与隔离

| 层次 | 构造要求 | 目的 |
|---|---|---|
| 单事实提取 | 单块包含完整依据 | 测事实吸收 |
| 跨旧边界关系 | 必须结合旧边界两侧 | 测切块修复 |
| 远距离组合 | 需要多个远隔事实 | 测组合能力 |
| 条件与例外 | 区分适用与不适用场景 | 测过度泛化 |
| 通用与 Agent | 既有冻结协议 | 测能力维护 |

书内吸收探针允许支持事实出现在训练书中，但问题、表达和组合任务应独立构造。用于声称来源外泛化的评测还应隔离来源/概念，二者不能混报。用开发题选择切法后，最终盲测不能继续参与选择。

历史直接/改写题面 CPT 已训练的 1,672 题不能作为这些污染候选的独立盲测；纯书籍候选必须与污染候选区分。[R8]

### 9.4 如何解释结果

- B 主要改善跨旧边界题，且事实与回归稳定：支持 H1，仍需重复性检查。
- 原文 loss 降而问答不动：没有证明知识使用改善。
- 两条事实均答对但组合失败：优先研究提取与组合，而非只加遍数。
- 单事实仍错：先排查覆盖、标签、吸收和提取方式。
- 独立表现随曝光恶化或回归受损：停止扩大曝光，复查训练强度与遗忘。

实用收益阈值、回归容忍度和评测规模须在运行前登记；报告逐题配对变化及不确定性，避免对少量题目翻转作过强归因。

## 10. 未来实施的验收要求

1. 完整覆盖应保留原文，识别遗漏和额外重复监督。
2. 实际 tokenizer 计数、预留 EOS、超长明确失败。
3. 保存每遍切点和来源区间，可重建输入及审计关系覆盖。
4. 前缀 mask 与 next-token 移位对齐，新正文首 token 正确受监督。
5. 分列正文、前缀、标题、分隔符、EOS 的输入和目标曝光。
6. 拼接片段时明确 attention 行为，不以 EOS 代替隔离检查。
7. 指代展开、关联说明核查来源，保持条件、否定和例外。
8. 数据合同明确区分切法变化、新增内容与训练目标变化。

这些是未来工程要求，本次没有执行实现或新训练。当前最合理的推进方式，是先做预算匹配的 A/B 小规模对照，再决定是否投入重叠、长序列和关联文本；本报告不构成训练已启动或方案已奏效的声明。

- [P1 Allen-Zhu 与 Li，Physics of Language Models: Part 3.2, Knowledge Manipulation，ICLR 2025](https://openreview.net/pdf?id=oDbiL9CLoS)：受控实验中知识提取与操作表现不同，不是本项目切块因果证据。

上述外部来源已在本次讨论中检索核对。对变化切块的收益采用机制假设和实验建议表述，没有引用尚未开展的项目结果。
