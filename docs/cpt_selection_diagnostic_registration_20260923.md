# 多选完整性与判断形式：独立诊断登记

日期：2026-09-23。用户在80次矩阵准入关闭后授权继续。本批独立于已关闭的训练批次，不改变其结论，不训练、不重评正式集、不晋级。

## 先复算、后测量

固定使用上一批全部4道运输开发题MT1–MT4，含2道不稳定题和2道保持题，原题条件、四个选项和冻结标签不变。不新制题，不根据本批结果筛题。先将旧40次输出还原到原选项身份，检查漏选是否固定内容、位置或批次；旧输出保留，不当作新调用。

新实验比较三种判断形式，均不追加来源，保留完整题干和全部选项：

1. **S，集合**：精确复用原消息，返回所有正确索引。新增同场对照用于判断旧失败是否在当前执行中重现，不能只把新形式和一次历史错误比较。
2. **V，逐项向量**：四个选项均在同一提示内，返回按显示位置排序的四个布尔值。仅替换作答指令，不提示正确项数、不提示旧遗漏位置、不要求解释。
3. **B，单项判断**：仍显示全部四个选项，每次指定一个显示位置，返回该项是否成立的布尔值。四次独立请求重建集合；不能把其四倍调用代价藏成免费收益。

每题四种既定循环排列。S/V每个排列各1次，第一排列各再2次，分别24次；B每排列四项各1次，第一排列每项再2次，共96次。**总上限144次**，只用既有P1权重。重复用于检查输出稳定性，不当作独立样本或训练种子。不能追加调用追求显著结果。

## 冻结协议与质量检查

温度0、种子1024、最大输出96 token、最大序列8192、TP8、相同既有推理环境。每批最多16请求，按题号、排列、S/V/B项序构建主轮，然后两个第一排列重复轮；完整顺序随私有包冻结。不同输出形式改变提示与计算结构，因此不能声称纯粹分离格式单因素，也不能把同提示波动确定归因于运行环境。

构建器不读取正确标签来拼提示。V/B仅机械去掉原末尾选择指令，替换输出约定；其余题干/选项保持。S提示文本及token指纹须与旧记录一致。独立审阅者核验这一点、无标签泄漏、计数、保留项、严格评分与解释边界后才运行。设备锁和实际空间通过，未决预登记查清前不能重发。

V严格要求`{"supported":[true,false,true,false]}`形式（此处仅说明类型，固定示例不得进入提示）；B严格要求`{"supported":true}`形式。不接受0/1、字符串布尔、缺项、重复键或多余字段。S沿用正式解析器。所有形式均以同一冻结标签按排列映射回原选项，完整集合完全匹配才计题对；B缺任何子调用、无效或截断都不算完整正确。

## 固定报告和判定

同时报告：每形式四排列全对题数、16个题×排列的完整集合正确数、每原选项的漏选/误选、第一排列三次完整集合及逐项稳定性、调用数和输出token。MT2/MT4保持题单独报告。不能将64个单项当64道独立题。

- 同场S也稳定恢复：旧失败未稳定重现，不能把V/B的成功算作形式收益。
- S仍漏选而V完整：支持完整逐项输出配方的开发信号，不证明内部知识已完整。
- S/V不完整而B正确：支持分开判断可能有用，同时披露四倍调用与上下文/决策结构差异。
- 三者都失败：当前简单重表达没有解决；结合错误项一致性再定位，不直接诊断为缺知识。
- 修复伴随保持题退化、误选增加或明显重复波动：登记代价与不稳定，不宣布有效方案。
