# P3预登记：固定配比，替换新增回放的内容

2026-09-17。这是P2之后、任何P3数据制备及模型查询之前的设计登记；不是已完成的训练记录。

## 问题与比较

P2增加的是以定义和边界判断为主的旧题重复，保持评测却以数值应用为主。下一对照只检验：**用独立通用算术练习替换60条额外旧题回放，能否在保留迁移信号时减轻数值能力的损失？** 不把该试验称为梯度冲突测量，也不宣称所有因素已被完全隔离。

对照使用已完成且冻结的P2，不重训P2或挑选较低基线。处理臂P3从同一Step120 HF重新初始化，使用新优化器；相同315条、batch3、105步、1遍、5e-7学习率、训练seed1、分布式配置和实际采样顺序。

P2为120次新目标曝光+135次基础历史回放+60次额外旧题回放。P3仅替换后60条记录，剩余255个位置的消息和监督逐字不变。仍是120+195的目标/保持曝光配比；被替换的60条从重复概念题改为新的算术练习。这一干预同时改变内容、独特样本数及token长度，不能宣称只隔离了“算术”这一属性或精确匹配计算预算。

## 新任务的边界与冻结办法

生成器只使用本文件规定的操作和本地确定性伪随机数，不读取80道保持题、其来源/标签/预测、官方评测或本轮逐题审查结果。题面只含整数表达式与四个候选整数，不出现物流、吨公里、资本净值、再订货点、载荷等情境或术语。

固定四种操作，各15道训练题：三整数相加、连续两次相减、两个乘积求和、整除。数字由seed71437生成，绝对值2至99；减法允许负结果；乘积求和允许有符号因子；整除由非零除数与整数商生成被除数。四选项随机排列，单正确答案，错误值应唯一且与正确值不同，不复用保持集的干扰项规则。使用答案JSON监督，不增加解释、思维链或新系统提示。

另以seed71438生成四种操作各15道、共60道不训练的算术检查题。训练与检查须按规范化表达式排除相同和交换等价的重复，包含负数、不同操作及结果范围；它是同类运算的新表达式检查，不能称广域泛化测试。生成、选项计算和发布核验要分离实现；逐题使用精确整数运算校验，尤其负数和整除，不靠语言模型定标签。保留全量题目、证据和构建指纹于私有目录。

60条训练题按固定操作名、题ID排序，依次替换P2已有replacement_map的60个位置。任何质量修复必须在首个新测量前另立版本冻结，不根据模型结果重写。

## 开训前与测量预算

1. 核对P2指纹、255条逐字不变、120次目标曝光、135个基础回放及60个新算术样本；新检查题和既有保持/封存不得进入训练加载器。
2. 实际分词并独立验证监督边界、EOS、最大长度、训练器加载和采样顺序。记录相对P2的78,602序列/8,770监督token变化，不用无关填充匹配token。
3. 新60道算术检查题先由固定Step120和P2各测一次，共120条。即使出现天花板，仍保留全部结果，不提高难度后重测；它仅用于发现训练后的计算退步。
4. 在已知两份前测的情况下，仍只执行预先固定的一次P3；除发现数据/实现错误外不据分数修改配方。若实现或质量门槛失败，修复并记录，不能冒充完成实验。
5. P3后测用原180题加新60道算术检查题，共240条，各一次。沿用temperature0、seed1024、thinking关闭、96输出、8192上下文、TP8/maxseq32。总计新增360回答、一次105步训练，不测封存或正式双集，不增加旧题拟合重测。

## 结果判断与停止

- 原40迁移题按两个已有Step120基线分别报告：每层至少净增2题，且各至少2个规则族净改善；保留原始前后标签和评分。
- 原保持集至少52/80，达到两个基线中较高者；逐族、逐题同时报告。不能用算术检查成绩替代这个门槛。
- 新60道算术检查成绩不得低于Step120和P2两份已冻结前测中的较高者，报告四类操作，不能用总分掩盖退步。
- 全部通过才进入扩大数据与独立确认评审；不自动进入C/D或宣称正式+3个百分点。原80题已用于路线选择，必须标为开发保持集，后续需要新广域保持确认。
- 任一失败就停止当前一次内容替换路线，不继续扫比例、学习率、重复次数、算术难度或选最好的随机seed。只报告这个受限干预的成败；若要另立方法，先根据累计证据重新评审成本和目标。

现有135旧训练题拟合诊断是解释性证据，不是P3晋级门槛。若它暴露实际训练消息、标签或加载问题，则优先修复实现并重新评审本设计；否则不据其分数更改以上60条配方。
