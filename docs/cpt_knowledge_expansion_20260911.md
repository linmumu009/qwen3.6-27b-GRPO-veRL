# 300道错题的知识材料整理（2026-09-11）

本轮按用户要求整理13份材料中的相关定义和关系，并补充维基百科及其他权威来源。交付的是可阅读的知识整理文档、来源证据和候选材料；没有启动训练，也没有把仍存在冲突或解析问题的候选宣布为可直接预训练的最终语料。

## 无冲突要求的实际处理

已确认两类具体错误不能为了符合标签而写进教材：零部件随成品用量推导的需求属于相关需求；平均正应力应为力除以面积。其核对依据分别是 [Business Central计划定义](https://learn.microsoft.com/en-nz/dynamics365/business-central/design-details-balancing-demand-and-supply) 与 [MIT应力讲义](https://www.ocw.mit.edu/courses/6-152j-micro-nano-processing-technology-fall-2005/4e555db93fbd2b7473f14100fbaadcc8_lecture13.pdf)。

其他问题包括：承运人与托运人角色混用、选择项内部矛盾、缺少图形编号、企业系统配置被写成通用规则，以及旧版/新版术语混排。未标记的其余题仍需核对，不能自动视为正确或无冲突。82题的问题类别可重叠，详细统计见配套安全JSON。

处理原则是保留所有来源材料，核查具体断言；可由适用地区、年份或定义维度解释的差异写清条件。无法解释的冲突留在清单中，不把某一答案硬改成所谓权威知识，也不在本轮修改评测标签。训练就绪状态保持false。

## 对多版本知识CPT的判断

方向合理：同一知识在不同表述和关系上下文中出现，有望改善提取和应用，而不只是记住原句。[Synthetic continued pretraining](https://arxiv.org/abs/2409.07431)以实体关系扩展小规模文档；[Enhancing LLM Knowledge Learning through Generalization](https://aclanthology.org/2025.findings-emnlp.469/)讨论多样上下文的价值，也指出改写可能改变事实。这些研究提供方法依据，不保证本项目的收益幅度。

建议以知识单元为采样单位，而非某主题有多少道重复错题。每个单元先组织“精确定义、同义/上下位关系、易混概念区别、边界条件、必要公式或实例”，再选择真实的不同来源。相同教材的镜像下载或同一百科跳转只算一个来源；措辞近乎一致的段落不应无限放大权重。若合成改写，需保持实体、数字、单位、否定词和条件一致，并记录其不是独立来源。

下一次训练前需完成候选的逐条语义与版面审核、解开已知冲突、验证公式，才生成正式分词和长度合格的训练文件。本轮没有宣称“所有相关定义已经穷尽”，也没有完成全部300题的逐条无冲突证明。缺失原图及企业规程的题仍需要相应原资料，不能由维基百科补成确定答案。

评测已用于发现知识缺口，因此本轮属于针对已知评测补知识；同两套评测可用于跟踪修复，但泛化需要额外独立题目验证。对多版本方案与简单重复方案的比较应尽量保持起点、训练token预算和评测设置一致。

## 可复现与隐私

工具为 `fetch_cpt_wikipedia_sources.py`、`collect_cpt_knowledge_evidence.py`、`render_cpt_knowledge_collection.py`。百科采集仅向公开接口发送概念标题，未发送私有题干、选项或答案。文档、教材摘录、私有索引和候选正文均留在本地，不提交Git；仓库只提交工具、说明和汇总指纹。

维基百科曾限制访问频率，采集器已降低频率、保留检查点并补齐剩余条目；也修正了批量接口只返回一个全文的行为，未将空正文计作已收集。最终有效版本和文件指纹以 [交付清单](cpt_knowledge_expansion_20260911.safe.json) 为准。
