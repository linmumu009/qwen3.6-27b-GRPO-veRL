## 一、决策摘要

下一阶段先确认可修复空间和数据价值，再执行两个受控候选。核心问题是：

> 在有充分来源、原模型确有缺口的能力上，直接补充知识是否足够？更强调适用条件、竞争规则和情境变化的监督，能否增加稳定迁移，并保住原有能力？

本计划分为四个阶段：

| 阶段 | 工作 | 必须得到的结论 |
|---|---|---|
| A：可修复空间 | 审阅现有共同错误，建立来源与能力台账 | 哪些问题具备可信的训练解决路径，哪些先缺资料或裁定 |
| B：训练价值 | 来源独立制题，检查闭卷与给证据表现 | 是否存在足够多“确实不会、证据能支持、题目可信”的能力组 |
| C：两臂训练 | 同起点、同知识范围、同保持数据，比较两种教学方式 | 直接知识监督与迁移导向监督，哪种能带来更好的净收益 |
| D：固定后测 | 同时测独立迁移、保持及正式双集 | 是否值得重复确认、扩覆盖，或者停止当前制数配方 |

## 三、待检验的解释

| 编号 | 解释 | 应观察到什么 | 什么结果不支持它 |

| H1 | 有效知识覆盖不足 | 新的、有来源支撑的缺口可以被直接监督修复，并迁移到新题 | 训练学会但同规则新任务不改善 |

## 四、阶段 A：建立可修复空间台账

### A1. 范围与优先级

复用1672条现有台账和全部原始预测，不重复正式推理。对SC32、Logistika237条共同错误逐条做基础判定；此前43条变化及已有审阅作为补充。先完成SC全量，再按Logistika类别与题型处理，不能只挑容易找到来源的案例。

每条记录必须区分：

1. **来源充分、答案可唯一推出**：可以提炼能力规格，但原题禁止进入制数。
2. **只有相邻知识或部分前提**：记录缺失事实，不记为已覆盖。
3. **缺图、企业规则、版本或流程上下文**：转资料补全清单。
4. **候选语义重叠或标签待裁定**：保留官方计分，单列争议。

逐条填写题目哈希、能力组、来源定位、适用范围、输入充分性、标签唯一性、实际SFT覆盖以及未解决项。来源目录存在与实际训练消息出现是不同字段。对每个能力组关联的题数去重，不能把重复题、同一图或共享词表当作独立知识点。

### A2. 交付与判断

- 私有逐题台账；公开安全汇总只含统计、能力描述和来源标识。
- SC与Logistika分别报告可信可修复条数、未知条数、争议条数和能力组数。
- 候选来源先从现有归档寻找；需要外部补充时保存原文、版本和定位，来源未核实前不得制成训练答案。
- 若可信覆盖的去重题数不足P1剩余目标差距（SC4、Logistika31），标记“当前来源无法支撑目标所需空间”；优先补来源，不承诺靠现有候选达标。
- 达到这个数量也只是必要的空间检查，**不代表这些题可通过训练全部修复，更没有预留回退余量**。同时报告来源共享、跨能力重叠和分类不确定性。

时间上限：约2个工作日的资料与台账工作，属于排程估计。到点输出已核实范围和未解决清单；不得把未审阅项目自动记成可修复。全量基础判定未完成时，不宣称完成总体覆盖判断。

## 五、阶段 B：先证明候选有训练价值

### B1. 制题与正式数据隔离

最多选择24个候选能力组，初始名额SC相关6组、Logistika相关18组。选择依据是来源充分性、真实缺口和覆盖价值，名额不是凑数要求。粗类别不能直接决定任务：每组必须写出实际判断操作、竞争概念、输入条件及目标范围。

审计侧可输出抽象能力规格和来源标识，不输出正式题干、选项、标签、原始回答或图号。制题应在未读取正式题内容的独立上下文或由独立编写者进行；熟悉正式题的审阅环境负责隔离排重与合规检查。本轮文档不预先生成任何正式题改写。

每组先写4道筛选诊断题，覆盖定义范围、相近概念、条件应用和反例。全部只用于选择能力方向，不进入训练、开发或确认集。条件不适用时说明替代任务的测量目的，不强行套四种题型。

任务形态须保留所测能力的关键难度：分类框架竞争不能替换成简单设备命名，多选集合不能全改成单选，长候选辨析不能仅用四个明显不同的选项。候选数按能力规格确定，干扰项须有来源且不存在同义正确项；不复制正式共享词表。四种顺序不等于每题只有四个选项。若窗口或来源无法支持该任务形态，明确记录测量缺口。

### B2. 固定推理与预算

每题使用4种预先固定的选项顺序。交换选项后语义必须不变；含“以上”、位置指代或等价答案的题先修订，不勉强排列。

| 测量 | 模型 | 最大调用数 |
|---|---|---:|
| 闭卷诊断，24组×4题×4顺序 | Step120、P1 | 768 |
| 同题提供充分短证据，24组×4题×4顺序 | P1 | 384 |
| 同提示运行稳定性，固定抽取24个闭卷提示各追加2次 | P1 | 48 |
| **合计上限** | | **1200** |

稳定性提示在看分数前按固定哈希抽取；少于24个时全取。全部调用一次登记，不针对错误题反复补测。四顺序有相关性，只按原题和能力组统计；同提示追加用于辨别运行波动，不替换主结果、不取最好答案。

闭卷沿用已验证的推理协议；证据条件只增加已核实的短材料，不提供答案标签。正式评分提示和预算不改。若材料加题目超出窗口，先在模型调用前解决，不静默截断。

### B3. 能力组进入训练的条件

四顺序全对称为该诊断题“稳定正确”。主分析使用最初四次回答，运行重复另列。

- 来源与标签逐项核验通过，竞争选项有唯一可判定结论。
- P1闭卷4题中稳定正确不超过2题，保证存在实质学习空间。
- P1给充分证据后至少3/4题稳定正确，且比闭卷至少多1题。
- 不依赖缺失图片、未知企业规则或未经裁定的同义标签。

这只选择“值得训练检验”的能力；给证据改善也可能来自注意力或消歧，不能证明权重内知识缺失。闭卷与给证据均差的组进入任务/推理诊断清单，不与可训练组混合解释。闭卷已会的组可候选保持，不按新知识计数。

**进入阶段C的最低范围：12组，其中至少3组SC相关、9组Logistika相关；Logistika至少覆盖3种实质不同的判断能力。** 上限24组。数量是防止再次收窄为单一题族的设计约束，没有统计充分性含义。同一规则拆成多个模板不得重复计组。

若不足，不训练、不换简单题凑数。输出失败原因分布：已会、来源不足、标签不清、证据仍不能支持作答。下一轮应针对最大阻塞项修复数据生产。本阶段只允许模型查询前的质量修订；查询后的新题必须作为新版本重新登记，不能无上限筛到过关。

## 六、阶段 C：冻结数据后执行两臂训练

### C1. 新数据划分

设通过B阶段的能力组数为G，12≤G≤24。筛选诊断题全部退出以下划分。

| 分区 | 每组题数 | 总量 | 用途 |
|---|---:|---:|---|
| 训练 | 6 | 6G | 两臂各自的监督任务 |
| 迁移开发 | 4 | 4G | 表达2、条件组合/反例2；情境、模板与训练分开 |
| 封存确认 | 4 | 4G | 独立编写的新场景；仅在选出候选后打开 |
| 能力保持训练 | 全局48 | 48 | 12个相关保持能力各4题，两臂相同 |
| 能力保持评测 | 全局48 | 48 | 每能力另4题，模板与训练隔离，两臂共用 |

保持能力依据既有退化形态和目标任务范围确定，包括口径、条件、集合判断、数值应用及相关领域规则，不能全用通用算术或定义题替代。保留已有80题保持警报集，只作历史连续性观察。

开发与训练共享知识规则，检验跨任务迁移；封存确认是新任务确认，不宣称新知识或全新领域泛化。来源连通组、共享规则及模板关系必须登记，不能将题数当独立知识数。

封存确认在训练前由独立编写/复核过程准备并冻结；调参和候选选择不读取其题目与标签，也不运行模型。若无法实现内容隔离，明确降级为开发数据，停止“独立确认”的结论，不用改文件名代替封存。

### C2. 两个训练臂

| 项目 | K：直接知识监督 | T：迁移导向监督 |
|---|---|---|
| 起点 | Step120，相同初始化 | Step120，相同初始化 |
| 知识范围 | 同一G组来源、事实、适用条件 | 与K相同 |
| 每组6题 | 定义、正例、明确条件下的直接应用 | 竞争规则、条件变化、反例、适用范围识别及新组合 |
| 必须覆盖的原子事实 | 同一清单，逐项核对 | 与K相同，不偷加知识 |
| 选项顺序 | 每题三次曝光采用预定平衡排列 | 同一排列政策 |
| 监督表达 | 一次答案、两次简短依据加答案 | 同样比例、相近长度 |
| P1旧训练 | 原315条内容与共同部分相对顺序保留 | 完全相同 |
| 新保持训练 | 同48条、各曝光一次 | 完全相同 |
| 学习率/批量/遍数 | 5e-7 / 3 / 1 | 完全相同 |
| 训练种子 | 第一轮沿用已记录种子1 | 相同 |

K必须是合理的直接教学基线，不能故意使用低质量题或无意义重复。T改变的是一组任务设计，因此差异只能解释为**这套迁移导向教学方式的整体效果**，不能分离反例、条件变化或某一项技术的贡献。两臂都采用同一选项变换政策，本轮不识别乱序增强的单独效果。

K/T相对P1同时增加知识任务、能力保持和训练量；共同改善只能支持完整配方有用，不能单独归功于知识扩展。若未来需要识别这一贡献，再登记共同保持数据但不加新知识的对照；本轮不追加第三个初始训练臂。

不从P1权重续训，避免把起点和新任务设计混在一起。原315条保留不代表其整段训练位置不变；两臂用相同记录槽位、共同记录顺序及采样规则。新增任务成对占据对应槽位。

### C3. 训练预算

- 每臂记录数：315+48+18G，即579—795条。
- batch3、单遍时：193—265步；训练前按实际加载器核验。
- 每臂硬上限：400,000序列token、70,000监督token。总初始训练最多两臂。
- 两臂监督token相差≤3%，序列token相差≤10%，记录数和步数相同；这是近似预算匹配，不称严格等计算量。
- 若超出或差异过大，在任何模型训练前通过等价表达长度调整；不得删关键条件、填无意义监督token或训练后按分数补步数。
- 冻结实际分词、来源、事实清单、数据/顺序指纹、模型身份和软件环境后开训。损失监测数据两臂相同，不用本轮迁移开发题选择检查点；只测最终检查点。

机器、卡数和运行时间沿用已验证环境后实测，不预报未经核实的小时数。两臂顺序执行，遵守现有资源锁，不影响其他实验。

## 七、阶段 D：固定测量、选择与确认

### D1. 初始两臂都必须完成正式测量

一旦训练、导出和数据完整性通过，K、T都执行以下后测，不因小型开发成绩差而取消正式测量：

1. 固定抽取每组2道训练题，4顺序，检查训练拟合和不变性。
2. 全部4G道迁移开发题，4顺序。
3. 全部48道新保持评测题，4顺序。
4. 原80题保持警报集，沿用原协议单次测量。
5. 正式1672题，原协议3次严格多数，共5016调用/臂。

Step120与P1先完成相同的新迁移开发和保持前测。训练抽样分为K/T两套，Step120分别前测，K/T各自后测自己的训练抽样；P1不做训练拟合抽样，以免不同题面被当作同题比较。两臂优劣由共同开发、保持和正式题判断。原80题和正式对照只在协议、输入与模型记录可比时复用。可比性失败则先提交需要重建的对照范围及预算修订，不混用旧成绩。

G=24时，四模型的新训练抽样/开发/保持最多3072次；K/T原保持新增160次；正式新增10032次；加B阶段1200次，**初始计划模型调用上限14464次**，不含制题、内容复核和后续确认。G不足24按公式下降。制题及复核如使用模型，必须另记调用/成本，不能隐藏在此上限中；候选任务数量固定，不反复生成到分数过关。

### D2. 主指标与报告单位

| 指标 | 计算方式 | 防止的误判 |
|---|---|---|
| 正式净收益 | 两集分别列正确数、修复、新增错，与Step120/P1配对 | 合并总分掩盖一集下降 |
| 稳定迁移 | 每题四顺序全对记1，否则0；表达和条件层分别报告 | 调用数上涨冒充规则稳定掌握 |
| 保持 | 新保持稳定正确数、历史保持警报、正式新增错误 | 单一保持小试替代全局保持 |
| 能力组覆盖 | 有改善/无变化/退化的组数与组内差值 | 大量同模板题制造虚假样本量 |
| 运行稳定性 | 同提示重复的答案一致性，独立列出 | 把所有顺序差异归于位置 |

使用预登记的全部题目，不事后剔除难题。有效来源与标签发生争议时保留原分数，另给带明确理由的敏感性分析。正式官方评分不修改。

误差分析报告组内和组间差异；可以给按来源连通组重采样的区间，但组数少时明确不稳定。正式题的配对区间同样不能覆盖训练种子、反复选型及共享词表的全部不确定性。显著性不作为单一晋级开关。

### D3. 事前决策规则

以下采用固定整数门槛，避免看结果再挑口径：

- “迁移正向”：相对P1，4G道开发题的稳定正确数净增至少G（25个百分点），且表达层和条件层均净改善；至少一半能力组有正向变化，并且至少一个SC相关组、三个Logistika相关组改善。
- “新保持可接受”：48题稳定正确数最多比P1少1题；同时逐组列退化。原80题出现下降只作为警报，不能仅凭一题差异自动推翻其他证据。
- “正式正向”：两集均不低于P1，且至少一集提高。最终达标仍要求196/1224；小幅提高只够候选资格。

25个百分点针对本计划主动筛选出的缺口组，是较强工程收益要求，并非理论阈值。它不会取消任何已启动候选的正式测量。若迁移门槛未过但正式明显改善，应记录“代理指标可能失配”，执行下表的有限确认，不事后改为迁移通过。

| 观察结果 | 决策 |
|---|---|
| K/T均只改善训练题 | 停止当前制数/教学配方扩量；核查真实任务差异，不追加学习率或曝光搜索 |
| K有效，T没有额外收益 | 优先直接知识监督；当前没有复杂任务设计的增量依据 |
| T在稳定迁移更好，正式也正向，保持可接受 | 进入有限确认；支持这套教学方式值得继续检验 |
| 迁移改善，但正式无改善或一集下降 | 不升级；检查迁移指标与正式任务对应，保留分层结果 |
| 正式达到196/1224，但迁移门槛未过 | 进入有限确认，标记泛化机制未解释；不宣布迁移路线已验证 |
| 正式只有小幅上涨，迁移门槛未过 | 不追逐单题波动，保持P1，不扩大当前配方 |
| 只有来源/任务审核通过，模型已经会 | 可作保持候选，不能以新增知识成果进入训练扩量 |

两臂都具备确认资格时，先选两集正式收益均不劣、至少一集更高的一臂；若互有高低，按各集相对P1增益占剩余目标差距的比例，取两者较小值更大者：min((SC−192)/4,(Logistika−1193)/31)。再同分时比较稳定迁移和新保持；仍同分选K。该规则在看成绩前固定，仅用于工程选择。

### D4. 最多一次训练重复及封存确认

有候选符合上述资格才执行：同一数据、配方和最终检查点政策，用训练种子2重训一次，禁止同时修改数据。最多增加一臂，最多400,000序列token、70,000监督token。

在确认集打开前冻结候选身份及全部判据。对选中候选的两个种子、P1、Step120各测4G道封存题的四顺序；新增种子完成D1相同后测，包括正式5016次。G=24时，新增种子后测为768+80+5016=5864次，四模型封存确认1536次，确认阶段上限7400次；与初始计划合计最多**21864次推理、三次训练**，不含独立登记的制题/审阅成本。

重复种子须再次满足正式正向和新保持条件；封存稳定正确数对P1至少增加G、两迁移层均改善。若宣称最终目标达成，两个训练种子都须达到196/1224。两次训练仍不足以充分估计种子方差，只能称重复确认，不称普遍稳定性已证明。

确认失败则保留探索性结果、停止扩量，不继续换种子取最好成绩。封存题一经打开即转为已用确认集；后续版本不能继续称其未见。

## 八、成本、停止与下一轮边界

- A/B没有形成足够合格缺口：停在数据与来源阶段，输出短板，不启动训练。
- C初始只运行K/T两个候选；D最多一个候选换种子确认。无自动超参搜索、无挑检查点、无错误题重测取高分。
- 数据、实现或运行故障可按原登记恢复，记录中断及复用范围；恢复不能更换训练或评测判据。
- 若K/T均失败，下一轮优先改变任务生产与能力测量，不默认扩大同一配方。若有稳定净收益，再扩知识范围。
- CPT16+同一SFT的起点对照推迟到SFT数据展示可重复收益之后；本轮结果不能裁定CPT是否有价值。
