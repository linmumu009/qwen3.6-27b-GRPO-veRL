# Qwen3.6-27B / Step120 全书记忆筛查与 CPT 启动门禁

日期：2026-09-03

## 直接结论

**没有发现原生模型或 Step120 对这本书的强书籍特异性逐字记忆证据；继续使用该书仍有边际价值，但一本书不足以支持 27B 模型的正式领域 CPT，当前也尚无经验证的 Qwen3.5 causal-LM 训练入口，因此本轮不改变模型权重。**

本轮已经解除此前的授权等待：用户明确确认已取得覆盖 AI/ML 训练的书面授权。仓库只记录这项用户确认；授权文件没有提供给执行方审阅，不能把该记录表述为独立法律核验。

下一步应把本书作为 5M-token 混合 CPT 金丝雀中的一个来源，并先补足多来源授权物流语料、一般能力回放以及 Qwen3.5 一步前反向门禁。不能把整本书装进 assistant 回复后运行 SFT，并将其称作 CPT。

## 取证设计

- 数据只在本地工作区和 5 号机私有目录处理，没有把受限正文发往百炼或其他第三方接口。
- 比较对象为 5 号机本地原生权重与 Step120 HF 导出；两者使用相同 vLLM-Ascend 镜像、同一台机器、同一并行与生成配置。
- 从全书按 token 等距分层抽样，分别使用 32、64、128-token 前缀，每档 200 个互不重叠窗口，目标续写统一为 32 token；同档两模型由相同 seed 确定，逐条 `case_id/source_hash` 配对。
- 每个正式档位并发 64。显式同时关闭顶层 thinking 和 chat-template thinking；两模型在正式运行前各以 4 条探针验证 final content 非空，探针不计入结果。
- 指标包括最长连续精确前缀、token F1、5/10/20-token 命中率、逐样本增减以及两个模型回答完全一致率。这里的 token 是可移植正则分词，不是 Qwen tokenizer token。

## 全书续写结果

| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 32 | 0.575 | 0.580 | +0.005 | 6 / 6 | 2.0% / 2.0% | 0 / 0 | 0 / 0 |
| 64 | 0.705 | 0.700 | -0.005 | 11 / 11 | 1.5% / 1.5% | 0.5% / 0.5% | 0 / 0 |
| 128 | 0.855 | 0.865 | +0.010 | 15 / 15 | 2.5% / 2.5% | 1.0% / 1.0% | 0 / 0 |

六个正式档位共 1,200 次请求，成功 1,200、API 失败 0、空 final content 0、reasoning-only 0。按 600 个提示聚合，每个模型都是 12 个 ≥5-token 命中、3 个 ≥10-token 命中、0 个 ≥20-token 命中。Step120 相比原生模型的连续命中长度为 5 个提高、4 个降低、591 个不变；两者没有出现任何 ≥10-token 门槛转移。

模型回答逐字完全相同率在三个前缀档分别为 73.5%、75.5%、69.0%。这说明本轮 CRPO/开源后训练没有产生可观察的本书续写记忆增量。

## 高命中样本复核

三个 ≥10-token 样本均由原生模型与 Step120 以相同长度命中：

- 11-token 样本是公开常识性的 LEED 等级定义，随后模型改为自己的措辞，不是长段书籍特异性续写。
- 10-token 样本是托盘重量/尺寸表格中的数值单元；相同命中序列在源文件中出现 5 次。
- 15-token 样本是公开政府温室气体换算因子网页路径，模型随后给出了与书中不同的归档标识。

因此，这三条是通用知识、重复表格或公开 URL 结构的可预测续写，不足以认定模型记住了本书独有正文。另一方面，600 个抽样窗口仍不可能证明训练集成员关系的绝对否定；正确表述是“未发现强正证据”，不是“证明未进入预训练”。

## 是否继续用这本书

可以用，但不能单独用。

前置审计测得主正文约 370,380 个 Qwen token。只曝光一次时，它只占 20M–50M 独特物流语料目标的约 1.85%–0.74%；即使在 5M-token 金丝雀中也只占约 7.4%。这正适合作为高质量骨架来源，但不足以覆盖运输、仓储、库存、采购、供应链计划、履约、海关法规和企业操作知识的长尾。

推荐的第一批 5M-token 金丝雀构成为：本书清洗正文约 0.37M、其他多来源物流文本约 3.4M、一般能力回放约 1.2M。书籍最多曝光一次；不以重复本书来凑 token。进入正式 20M–50M 语料池时，保留逐文档来源、版本、许可、哈希和去重血缘。

## 为什么尚未启动权重训练

5 号机存在两个看似可用但尚未通过门禁的入口：

1. `mindspeed-llm-26.0.0-a3-sshd-yehairui` 有 `pretrain_gpt.py`，但其 Transformers 4.57.1 不识别 Step120 的 `qwen3_5` 配置；Qwen3-Next 示例不能直接当作 Qwen3.5-27B 的无损加载证明。
2. 原 Step120 veRL 容器中的 Megatron-Bridge 已包含 Qwen3.5-27B 转换和 SFT 配方，但随附 README 明确写明该模型的 pretraining 尚未验证。它能做 SFT 不等于已经具备经过验证的 raw-text causal-LM 路径。

直接启动会同时冒三个风险：错载混合 GDN/全注意力层、错误的 loss mask 把 CPT 变成 SFT、以及在没有可用旧 optimizer/RNG 的情况下产生不可复现或无法安全恢复的全参状态。因此本轮将“未改权重”作为正确的 fail-closed 结果，而不是未完成训练。

## 下一执行顺序

1. 清洗本书：只保留 `PART ONE` 到 `REFERENCES` 之间的正文，剔除页眉页码、图形占位符、参考文献与索引，修复明显断词，并生成私有文档级 JSONL 与安全质量清单。
2. 建设 5M-token 混合语料：Wikipedia 用于概念广度，政府/国际组织和已授权企业材料补规则与实务，一般开放语料做 20%–25% 回放；与 LogistikaBench、SC-bench 及未来隐藏集做逐字和语义去重。
3. 基于已支持 Qwen3.5 的 Megatron-Bridge 单独实现 raw-text 全 token loss 配方；先完成 HF→Megatron→HF 无训练往返一致性，再运行 1 step、不保存模型的前反向门禁。
4. 门禁必须检查 loss mask、MTP 辅助损失、梯度有限性、16-NPU 拓扑、峰值显存、checkpoint round-trip 和 model-only 导出。任何一项不通过都不进入正式 5M token。
5. 通过后从 Step120 model-only 权重初始化新 Adam，比较 `5e-8` 与 `1e-7` 低学习率臂；新 run 写入 `/data`，不写入已使用 97% 的 `/data3`。
6. 候选仍按既定门禁评测：隐藏物流知识至少 +3 点，LogistikaBench/SC-bench 仅作公开回归，原 Agent 与开源密封集不得下降超过 1 点；没有同时通过则不交付。
