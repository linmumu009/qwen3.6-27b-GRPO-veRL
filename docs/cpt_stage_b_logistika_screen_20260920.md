## 隔离、制题和放行

制题包仅有原始来源、出处及抽象能力规格；不含正式题干、选项、标签、原始预测和题目关联编号。构建程序仅读取三个已经核验的来源归档，并核对文件指纹。原文与全部生成内容保存在私有目录，Git 仅保存程序、规格、指纹和安全状态。

使用 Step120 在独立请求上下文中制题，再在另一请求中只提供来源和题干选项进行盲解审阅，隐藏作者答案和理由。最多 32 次制题、32 次审阅，不重试、不按分数补题。制题温度 0.4、种子 20920；审阅温度 0、种子 20921；输出上限 2048，窗口 8192，thinking=false，TP8，max_num_seqs=32。
