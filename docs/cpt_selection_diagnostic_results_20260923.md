# 多选完整性诊断：集合、向量与单项判断

日期：2026-09-23。对应[独立事前登记](cpt_selection_diagnostic_registration_20260923.md)。原矩阵训练批次保持关闭，本批不训练、不改变正式评分。

## 历史复算

旧4道运输题共40次输出中有5次错误，均漏选1项，没有误选。漏选发生在3个显示位置；同一道顺序比较题在不同来源条件下遗漏不同原选项。另一道题在相同首排列下发生对—错—对。错误分布于两个推理批次。

这些现象不能归结为一个固定位置或一个固定判断内容，也不能由批次成员关系推断硬件原因。旧4题第一排列均答对，故仅用一次默认排列会遗漏稳定性问题。

## 新对照的可解释范围

固定全部4题、原内容和四种循环排列。S列出所有正确索引，V一次输出四项真假，B保留全部题目/选项但每次只判断一项。S/V各24次，B96次，包含第一排列的三次测量，共144次。

S为新增同场基线；不能仅把V/B与旧一次失败比较。B每个完整答案集合需4次调用，不能把96次单项调用看作96道独立题。改变作答形式也改变提示和决策结构，结果是局部配方比较，不是纯格式因果分离或独立泛化。

协议经过隔离审阅。V/B严格校验JSON布尔类型和长度；B四项重建后与相同冻结标签比对。正式S解析器指纹与远端旧协议一致。4项针对性测试通过，覆盖严格类型、完整集合重建、截断及提示内容保持。

## 执行与结果

设备、空间、权重和协议预检通过；原S的16个提示已逐token对照历史指纹。9批144次均完成并下载，预测与批次指纹、调用数量、提示消息均复算通过。隔离审阅者不读取主审评分或汇总，从冻结标签独立重建全部集合，结果一致；见[独立核验](cpt_selection_diagnostic_execution_audit_20260923.safe.json)。无格式无效或截断。见[安全汇总](cpt_selection_diagnostic_results_20260923.safe.json)。

主轮以“同一题×同一排列”为配对单位，V相对S修复1个组合、损失3个；B修复1个、损失5个。两种改法均有局部修复，但总体更差；不是完全没有变化，也不是可靠收益。保持损失均发生在MT4；MT2三种方式全部正确。

S再次在与历史相同的两个主轮组合漏选，故旧问题部分重现；但旧MT1首排列的同提示波动本次没有重现。三种方式首排列的三次逐项输出全部一致，V/B在MT3却是稳定答错：重复稳定不等于判断正确。

含重复的24个完整集合中，S/V/B分别漏判2/6/8个正确陈述，均无误选。V/B给出了完整合法布尔输出，失败项明确是`false`，不是缺字段或少写一个索引。逐原选项的变化与重复稳定性已留在私有台账，公开报告不附题目或原始答案。

## 结论与下一方向

本批不支持把剩余问题主要解释为“模型都判断对了，只是答案列表没写全”。显式逐项输出和拆成单项请求都没有净改善，且各损失一个保持组合，B还付出4倍调用。因此不采用这两种新作答方式，不启动训练，不扩展到正式集。

这个反证也不能直接证明模型缺知识或不会某一步推理。输出约定、措辞和决策结构同时变化；“部分陈述正确”与“完整回答问题”的判据、时点/条件对应等解释仍未分离。仅4道已见开发题，不声称跨题泛化或确定内部机制。

下一优先级是对已冻结错误陈述做**条件—时点—结论的逐项核验**：先确认判据是否把“成立”和“覆盖完整问题”混在一起，再考虑独立登记显式状态表示对照。不得凭这次结果改写旧标签或自动生成更多训练样本。本批到144次结束，训练0、正式评测0、P1保留。

原始题目、选项、回答、逐原选项分析与审阅保持私有。仅发布固定协议、代码、计数和解释边界。
