## 新发现

1. **不是样本未被采到。** 用种子1重建333条采样顺序，指纹与实际加载器冻结值完全相同；逐步核对K/R共222个训练步，每批3条的序列token总量均与训练日志一致。6段原文各出现3次，assistant正文逐字核验。
2. **新增知识监督占比有限，但尚不能认定强度不足。** K原315条监督12,202token，新增1,071token，占总13,273的8.07%；18条新增记录占333条的5.41%。R新增1,236token，占9.20%。token份额不是梯度贡献份额，不能据此直接选择更高学习率或更多曝光。
3. **尚未测量原训练提示下能否答出原规则。** 全12个旧探针的system和user消息均与训练不同；训练要求解释概念及范围，后测拆为定义与例外，并要求无法回忆时说明不确定。因此K的0/36只能说明在这组调用提示下未通过，不能证明原提示下也无法复现。
4. **批次loss下降不等于规则记住了。** 每批3条，来源常与旧数据混合，第70步还含两段来源；各次出现的搭配不同。不能把这些批次loss连线当逐规则学习曲线。日志没有逐来源loss，也没有最终检查点在原训练提示下的来源条件似然。
5. **优化日志有线索，尚无因果诊断。** K有110/111步、R有106/111步报告的梯度范数大于配置裁剪阈值1，中位数分别35.19、37.19。两臂共同存在该现象，Adam也不允许把裁剪系数直接换算为有效学习率；不据此修改优化器。

| 观察 | 可以支持的结论 | 不能推出 |

| K在原提示仍不能完整调用 | 当前配方连原提示调用验收也未通过 | 参数中完全没有知识，或提高学习率必然有效 |
