# Qwen3.6-27B 对《The Handbook of Logistics and Distribution Management》第八版的逐字记忆预检

日期：2026-09-01

## 结论

本轮没有发现 Qwen3.6-27B 对该书第八版官方公开预览存在逐字记忆的正证据：64 条请求全部成功，连续精确命中 3、5、10、20 token 的比例均为 0。该结果仅适用于出版社产品页和 O'Reilly 公开展示的目录预览，不能证明完整正文没有进入预训练。

当前不应据此直接开始制数或训练。正式门禁仍是取得合规的完整电子文本或出版社授权样章后，按章节分层抽样并补充原文识别测试。

## 调用与数据边界

- 5 号机现有百炼 OpenAI 兼容配置可直接调用 `qwen3.6-27b`；64 并发下三组各 64 条请求均成功，未输出或复制密钥。
- 目标文本仅来自 [Kogan Page 官方产品页](https://www.koganpage.com/logistics-supplychain-operations/the-handbook-of-logistics-and-distribution-management-9781398625112)和 [O'Reilly 官方公开目录预览](https://www.oreilly.com/library/view/the-handbook-of/9781398625136/content/00_PRELIMS_s1_Halftitle.xhtml)。
- Kogan Page 的正文样章要求注册用户登录；5 号机和当前工作区中均未找到用户已有的该书电子文件，因此本轮没有绕过登录限制，也没有使用非授权下载来源。
- 原始目标文本和模型续写只保存在 5 号机临时目录，仓库仅保存不含正文、续写和凭据的汇总指标。

## 结果

所有测试均使用 32 token 前缀、16 token 目标续写、温度 0、关闭思考模式及并发 64。

| 数据 | 样本 | 平均精确前缀 | ≥3 token | ≥5 token | ≥10 token |
|---|---:|---:|---:|---:|---:|
| 目标书第八版官方公开预览 | 64 | 0.250 | 0.00% | 0.00% | 0.00% |
| 《双城记》著名开篇阳性对照 | 64 | 1.625 | 12.50% | 7.81% | 6.25% |
| 《双城记》全书随机片段对照 | 64 | 0.516 | 3.13% | 0.00% | 0.00% |

著名开篇对照出现了连续 5 和 10 token 的精确命中，说明当前接口和提示能够发现强逐字记忆。全书随机片段的命中率很低，同时说明自由续写本身对弱记忆的检出率有限；因此目标书的零命中只能解释为“未发现正证据”，不能解释为“确定没有见过”。

## 正式审计门禁

取得合规正文后再执行以下步骤：

1. 从不同章节抽取至少 200 个互不重叠片段，排除目录、标题、术语表和常见定义。
2. 同时运行 32/64/128 token 前缀续写，报告连续 3/5/10/20 token 命中及相对阳性、领域阴性对照的差值。
3. 增加原文与三个最小扰动版本的盲选识别，并轮换选项位置，避免仅依赖生成式续写。
4. 单独制作不复用原句的章节知识题，区分文本记忆和知识利用。
5. 若逐字记忆与知识题均高，则放弃把该书作为主训练源；若逐字记忆低且知识题低，才进入书籍制数和混合训练。
