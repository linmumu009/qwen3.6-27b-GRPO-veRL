# 全书能力型QA首批：436道已组织候选

2026-09-08。本轮完成批量数据建设，不再围绕6道旧题修补。实际产物为5号机私有数据：**训练候选365道、开发候选71道，共436道，覆盖44章**。已达到首批300–500道候选的规模目标，但尚未验证模型学习价值、尚未扩到2000–3000道，未启动SFT。

## 组织方式

从用户已授权教材CPT语料中选取107个有效来源片段，每来源最多生成6道独立QA。按章节轮转来源，不使用评测题、答案或错题主题作为生成输入。保留既有开发章节4、15、19、21、26、37；开发题不挪回训练。全书已被CPT见过，因此这里只是新SFT章节隔离，不是未见知识测试。

不再强制“一概念四个固定题型”整组生成。每道独立使用、独立接受或拒绝；来源/章节划分仍绑定，不能把同一来源改写后跨训练开发拆分。优先生成必要条件、概念辨析、新情境应用；只有来源支持关系式和假设才生成计算题。此批为英文开放问答，全部最终候选被生成器标为闭卷型；不意味着闭卷独立性已获得完备认证，也没有覆盖所有真实业务问法。

## 实际审核与数量核对

所有生成、只看学习者题面的审核、来源/答案/评分要点审核均使用5号机百炼qwen3.8-max，并发上限64。没有本地模型生成训练QA。

1. 4来源预检：生成24道，18道通过，达到预先设定的至少8道门槛后继续全批。
2. 107来源生成636道；初审接受453道。拒绝中包括题面审核65、结构14、来源审核24、词串重合4；另13个批次审核返回结构不合约，对应未完成审核的题不接受。后者为批次口径，不能与题级拒绝次数直接相加解释所有差额。
3. 词面近重复未检出；首次要求API返回453题完整语义分区失败，保留原响应，不推定缺失项通过。改为一次全局重复对检测，检出并移除11道；其中1个重复组件跨训练/开发，保留开发侧。未检出不等于已经证明没有语义重复。
4. 按划分/题型/模式每层至多2道抽检，共20道；API独立复核18道通过、2道剔除，剩440道。18/20不是总体质量率估计。
5. 当前任务审阅16道正文与教材依据，记录5项实质问题，其中1道已被API抽检剔除，新增隔离4道，最终436道。没有逐条重写或反复请求直到通过。

问题包括特定示例被称为标准指南、表格抽取关系不清、条件性结论被绝对化、特定库存缓冲被扩大为所有缓冲库存，以及安全相关技术表述缺少适用范围。安全相关问题仅隔离，未声称完成现行安全标准核验。其余未抽到的题仍可能包含同类缺陷，需要后续抽检/预答暴露系统问题，而不是将候选直接视为真值。

整轮337次API调用；返回计量共1,020,346 tokens（852,422输入、167,924输出），包含失败语义请求。此数不是现金账单。无自动重试、无目标模型预答调用、无训练调用。
