# Step120 单书 CPT 五项诊断复核

日期：2026-09-04
对象：`qwen3.6-27b-step120` → `qwen3.6-27b-step120-handbook8e-cpt`

## 结论先行

这轮 CPT **训练实际发生了，但没有形成可交付的物流知识增益，候选模型不应晋级**。

29 个 optimizer step 共处理 336,702 个含 EOS 的 sequence token，权重扫描确认 64 个语言层均有变化；然而变化幅度极小，语言参数相对 L2 仅 `8.46e-5`。这种微小更新只让书籍原文 NLL 相对下降 `0.398%`，没有达到预设 `2%` 吸收门槛；在改写知识题上为 `0` 增益，在三轮多数票公开评测上只净增 `1/1,672` 题，统计上完全不能区分于零效应。

因此，本轮不是“训练流程坏了”，而是“单书、单次曝光、`5e-7 → 1e-7` 的训练剂量太弱”。同一本书继续原样再跑一轮，证据收益低；把同一本书自动改成 SFT 问答也会引入自生成标签偏差，不能解决覆盖不足。

公开评测拆分：

- LogistikaBench：1,446 题，`81.604% → 81.674%`，净增 1 题（`+0.0692` 点）。

- 宏类别准确率反而变化 `-0.0818` 点，说明那 1 道净增不能解释成广泛领域提升。

## 为什么三轮复测是必要的

即使温度为 0、seed 相同、只有一个数据并行副本，当前 vLLM-Ascend 的异步调度仍产生少量逐题波动：Step120 三轮准确率为 `81.818% / 81.758% / 81.998%`，CPT 为 `82.057% / 81.818% / 81.938%`。Step120 有 1,646/1,672 道题三轮解析答案完全一致，CPT 为 1,658/1,672。

所以单次结果会被约 0.1–0.2 点的运行波动影响。逐题三轮多数票后，所有题都有明确多数答案；这比旧的 TP4×DP2 单次对照更适合作为本轮最终结论。

## 证据边界

- teacher-forced NLL 证明模型对训练分布的概率略有移动，不等价于知识问答能力。
- 续写测试用于排查逐字记忆风险，未发现新增长片段复现；它不能证明不存在任何形式的记忆。
- 改写知识题由 Step120 在本地根据私有书籍生成，经过结构、答案长度、重复题和连续 4 词重合门禁。由于基线模型参与出题，94.5% 的绝对分数偏乐观；但完全相同题目的配对差值仍能说明 CPT 没有产生可见变化。
- 公开题从原 matched-runtime 私有结果恢复题面与金标，旧预测字段被忽略；两模型使用同一个冻结文件并验证 item hash。安全结果不包含书籍正文、题面或模型原始回答。

## 下一步安排

1. **交付侧先用 RAG 补知识，不等待参数记忆。** 把已授权书籍和企业物流资料做可追溯检索，知识回答要求引用证据；如需格式稳定性，只做少量行为/引用格式 SFT，不把它宣传为知识注入。
2. **参数训练改为多来源混合 CPT 金丝雀。** 目标至少 5M 个去重物流 token，单本书不超过总领域 token 的 10%，并加入 10%–20% 通用回放；训练集与 SC-bench、LogistikaBench 继续做字面和语义隔离。
3. **先做学习率/训练量金丝雀，再跑全量。** 在相同 50-step 子集上比较 `1e-6` 与 `2e-6`，每个检查点立即运行本报告的固定 NLL、改写题和通用/Agent 回归；选择满足吸收门槛的最小学习率，而不是直接拉高。
4. **金丝雀门槛。** 书内固定 NLL 相对改善至少 2%；独立改写题至少 `+1.5` 点；公开/通用与原 Agent 关键指标均不得下降超过 `0.5` 点。未同时通过时不扩到完整 5M token。
5. **最终晋级门槛。** 冻结 SC-bench/LogistikaBench 三轮多数票至少 `+3.0` 点，同时原开源能力不降、垂域 Agent 增益保留；否则维持 Step120 + RAG 方案。
