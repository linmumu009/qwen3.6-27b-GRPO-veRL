# Repository Instructions

## Versioning and delivery

- For every completed update to this repository, update `README.md` with a version entry that includes the version number, date, and a concise summary of the changes.
- Include the README update in the same commit as the corresponding project changes.
- After verifying the work, commit it and push it to `origin/main`.
- Do not ask the user for routine confirmation before committing or pushing completed in-scope updates.
- Never include secrets, credentials, generated caches, or unrelated user changes in a commit.
